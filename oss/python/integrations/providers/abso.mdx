[Abso](https://abso.ai/#router) 是一个开源的 LLM 代理，它会根据提示复杂度在快速和慢速模型之间自动路由请求。它使用多种启发式方法来选择合适的模型。它速度非常快且延迟很低。

## 安装与设置

```bash
pip install langchain-abso
```
