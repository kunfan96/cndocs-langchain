>[Confident AI](https://confident-ai.com) 是 `DeepEval` 的创建者。
>
>[DeepEval](https://github.com/confident-ai/deepeval) 是一个用于对大语言模型进行单元测试的包。
> 使用 `DeepEval`，每个人都可以通过更快的迭代，利用单元测试和集成测试来构建健壮的语言模型。`DeepEval` 为从合成数据创建到测试的迭代过程中的每一步都提供支持。

## 安装与设置

你需要获取 [DeepEval API 凭证](https://app.confident-ai.com)。

你需要安装 `DeepEval` Python 包：

<CodeGroup>
```bash pip
pip install deepeval
```

```bash uv
uv add deepeval
```
</CodeGroup>

## 回调

参见一个[示例](/oss/python/integrations/callbacks/confident)。

```python
from langchain.callbacks.confident_callback import DeepEvalCallbackHandler
```
