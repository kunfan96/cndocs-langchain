[Bright Data](https://brightdata.com/) 提供了一个强大的网页抓取 API，允许您从 44 个热门网站提取结构化数据，包括电子商务网站（亚马逊、沃尔玛、eBay）、社交媒体（领英、Instagram、TikTok、Facebook）等，这使其对于需要可靠结构化网络数据源的 AI 代理特别有用。

## 概述

### 集成详情

|类名|包名|可序列化|JS 支持|版本|
|:--|:--|:-:|:-:|:-:|
|[`BrightDataWebScraperAPI`](https://pypi.org/project/langchain-brightdata/)|[`langchain-brightdata`](https://pypi.org/project/langchain-brightdata/)|✅|❌|![PyPI - Version](https://img.shields.io/pypi/v/langchain-brightdata?style=flat-square&label=%20)|

### 工具特性

|原生异步|返回制品|返回数据|定价|
|:-:|:-:|:--|:-:|
|❌|❌|来自网站的结构化数据（亚马逊产品、领英个人资料等）|需要 Bright Data 账户|

## 设置

该集成位于 `langchain-brightdata` 包中。

```python
pip install langchain-brightdata
```

您需要一个 Bright Data API 密钥才能使用此工具。您可以将其设置为环境变量：

```python
import os

os.environ["BRIGHT_DATA_API_KEY"] = "your-api-key"
```

或者在初始化工具时直接传递：

```python
from langchain_brightdata import BrightDataWebScraperAPI

scraper_tool = BrightDataWebScraperAPI(bright_data_api_key="your-api-key")
```

## 实例化

这里我们展示如何实例化 BrightDataWebScraperAPI 工具。此工具允许您使用 Bright Data 的数据集 API 从各种网站提取结构化数据，包括亚马逊产品详情、领英个人资料等。

该工具在实例化时接受以下参数：

- `bright_data_api_key`（必需，字符串）：用于身份验证的 Bright Data API 密钥。

## 调用

### 基本用法

```python
from langchain_brightdata import BrightDataWebScraperAPI

# 初始化工具
scraper_tool = BrightDataWebScraperAPI(
    bright_data_api_key="your-api-key"  # 如果已在环境变量中设置则可选
)

# 提取亚马逊产品数据
results = scraper_tool.invoke(
    {"url": "https://www.amazon.com/dp/B08L5TNJHG", "dataset_type": "amazon_product"}
)

print(results)
```

### 带参数的高级用法

```python
from langchain_brightdata import BrightDataWebScraperAPI

# 使用默认参数初始化
scraper_tool = BrightDataWebScraperAPI(bright_data_api_key="your-api-key")

# 提取具有特定位置定价的亚马逊产品数据
results = scraper_tool.invoke(
    {
        "url": "https://www.amazon.com/dp/B08L5TNJHG",
        "dataset_type": "amazon_product",
        "zipcode": "10001",  # 获取纽约市的定价
    }
)

print(results)

# 提取领英个人资料数据
linkedin_results = scraper_tool.invoke(
    {
        "url": "https://www.linkedin.com/in/satyanadella/",
        "dataset_type": "linkedin_person_profile",
    }
)

print(linkedin_results)
```

## 自定义选项

BrightDataWebScraperAPI 工具接受多个参数进行自定义：

|参数|类型|描述|
|:--|:--|:--|
|`url`|字符串|要从中提取数据的 URL|
|`dataset_type`|字符串|要使用的数据集类型（见下文可用类型）|
|`zipcode`|字符串|可选的邮政编码，用于获取特定位置的数据|
|`keyword`|字符串|搜索关键词（`amazon_product_search` 必需）|
|`first_name`|字符串|名字（`linkedin_people_search` 必需）|
|`last_name`|字符串|姓氏（`linkedin_people_search` 必需）|
|`num_of_reviews`|字符串|评论数量（`facebook_company_reviews` 必需）|
|`num_of_comments`|字符串|评论数量（用于 `youtube_comments`，默认：10）|
|`days_limit`|字符串|限制结果的天数（用于 `google_maps_reviews`，默认：3）|

## 在代理中使用

```python
from langchain_brightdata import BrightDataWebScraperAPI
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain.agents import create_agent


# 初始化 LLM
llm = ChatGoogleGenerativeAI(model="gemini-2.5-flash", google_api_key="your-api-key")

# 初始化 Bright Data 网页抓取 API 工具
scraper_tool = BrightDataWebScraperAPI(bright_data_api_key="your-api-key")

# 使用该工具创建代理
agent = create_agent(llm, [scraper_tool])

# 提供用户查询
user_input = "抓取纽约（邮政编码 10001）的亚马逊产品数据 https://www.amazon.com/dp/B0D2Q9397Y?th=1。"

# 流式输出代理的逐步结果
for step in agent.stream(
    {"messages": user_input},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
