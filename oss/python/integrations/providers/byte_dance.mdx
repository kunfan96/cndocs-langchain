## 文档加载器

>[飞书](https://www.larksuite.com/) 是由 `字节跳动` 开发的企业协作平台。

### 飞书文档加载器

参见 [使用示例](/oss/python/integrations/document_loaders/larksuite/#load-from-document)。

```python

```
