[KoboldAI](https://github.com/KoboldAI/KoboldAI-Client) 是一个“基于浏览器的前端，用于借助多种本地和远程 AI 模型进行 AI 辅助写作...”。它拥有一个公共和本地 API，可在 langchain 中使用。

本示例将介绍如何将 LangChain 与该 API 结合使用。

文档可在浏览器中通过在端点末尾添加 /api 来访问（例如 [127.0.0.1/:5000/api](http://127.0.0.1/:5000/api)）。

```python
from langchain_community.llms import KoboldApiLLM
```

将下面看到的端点替换为使用 --api 或 --public-api 启动 webui 后输出中显示的端点。

可选地，您可以传入 temperature 或 max_length 等参数。

```python
llm = KoboldApiLLM(endpoint="http://192.168.1.144:5000", max_length=80)
```

```python
response = llm.invoke(
    "### Instruction:\nWhat is the first book of the bible?\n### Response:"
)
```
