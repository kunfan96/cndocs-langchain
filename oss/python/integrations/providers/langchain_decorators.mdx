>`LangChain 装饰器` 是 LangChain 之上的一个层，为编写自定义 LangChain 提示和链提供了语法糖 🍭
>
>如需反馈、问题、贡献 - 请在此处提交 issue：
>[ju-bezdek/langchain-decorators](https://github.com/ju-bezdek/langchain-decorators)


主要原则和优势：

- 更加 `Pythonic` 的代码编写方式
- 编写多行提示，不会因缩进而破坏代码流程
- 利用 IDE 内置的 **提示**、**类型检查** 和 **文档弹出** 支持，快速查看函数、其使用的提示、参数等
- 充分利用 🦜🔗 LangChain 生态系统的全部功能
- 添加对 **可选参数** 的支持
- 通过将参数绑定到一个类，轻松在提示之间共享参数


这是一个使用 **LangChain 装饰器 ✨** 编写的简单代码示例：

``` python
@llm_prompt
def write_me_short_post(topic:str, platform:str="twitter", audience:str = "developers")->str:
    """
    为我写一个关于 {topic} 的帖子的简短标题，适用于 {platform} 平台。
    目标受众是 {audience}。
    （最多 15 个词）
    """
    return

# 自然地运行它
write_me_short_post(topic="starwars")
# 或者
write_me_short_post(topic="starwars", platform="redit")
```

# 定义其他参数
这里我们只是用 `llm_prompt` 装饰器将函数标记为提示，有效地将其转换为 LLMChain。而不是运行它


标准的 LLMchain 接受的初始化参数远不止 inputs_variables 和 prompt... 这个实现细节隐藏在装饰器中。
以下是其工作原理：

1. 使用 **全局设置**：

``` python
# 为所有提示定义全局设置（如果未设置 - chatGPT 是当前默认值）
from langchain_decorators import GlobalSettings

GlobalSettings.define_settings(
    default_llm=ChatOpenAI(temperature=0.0), # 这是默认值... 可以在此处全局更改
    default_streaming_llm=ChatOpenAI(temperature=0.0,streaming=True), # 这是默认值... 可以在此处为所有... 更改，将用于流式传输
)
```
2. 使用预定义的 **提示类型**

``` python
#您可以更改默认提示类型
from langchain_decorators import PromptTypes, PromptTypeSettings

PromptTypes.AGENT_REASONING.llm = ChatOpenAI()

# 或者您可以定义自己的类型：
class MyCustomPromptTypes(PromptTypes):
    GPT4=PromptTypeSettings(llm=ChatOpenAI(model="gpt-4"))

@llm_prompt(prompt_type=MyCustomPromptTypes.GPT4)
def write_a_complicated_code(app_idea:str)->str:
    ...

```
3.  **直接在装饰器中** 定义设置

``` python
from langchain_openai import OpenAI

@llm_prompt(
    llm=OpenAI(temperature=0.7),
    stop_tokens=["\nObservation"],
    ...
    )
def creative_writer(book_title:str)->str:
    ...
```

# 简化的流式传输

如果我们想利用流式传输：
 - 我们需要将提示定义为异步函数
 - 在装饰器上开启流式传输，或者我们可以定义一个开启了流式传输的 PromptType
 - 使用 StreamingContext 捕获流

这样我们只需标记哪个提示应该被流式传输，而无需费心于应该使用哪个 LLM，传递创建和分发流式处理程序到我们链的特定部分... 只需在提示/提示类型上开启/关闭流式传输...

流式传输仅在我们在流式上下文中调用它时才会发生... 在那里我们可以定义一个简单的函数来处理流

``` python
# 此代码示例是完整的，应能直接运行

from langchain_decorators import StreamingContext, llm_prompt

# 这将标记提示用于流式传输（如果我们只想在应用中流式传输某些提示... 但不想传递分发回调处理程序，这很有用）
# 注意只有异步函数才能被流式传输（如果不是，会得到错误）
@llm_prompt(capture_stream=True)
async def write_me_short_post(topic:str, platform:str="twitter", audience:str = "developers"):
    """
    为我写一个关于 {topic} 的帖子的简短标题，适用于 {platform} 平台。
    目标受众是 {audience}。
    （最多 15 个词）
    """
    pass



# 只是一个任意函数来演示流式传输... 在现实世界中会是某些 websocket 代码
tokens=[]
def capture_stream_func(new_token:str):
    tokens.append(new_token)

# 如果我们想捕获流，我们需要将执行包装在 StreamingContext 中...
# 这将允许我们捕获流，即使提示调用隐藏在更高级的方法中
# 只有标记了 capture_stream 的提示才会在此处被捕获
with StreamingContext(stream_to_stdout=True, callback=capture_stream_func):
    result = await run_prompt()
    print("流完成... 我们可以借助交替颜色区分令牌")


print("\n我们捕获了",len(tokens),"个令牌🎉\n")
print("结果如下：")
print(result)
```
# 提示声明
默认情况下，提示是整个函数文档，除非你标记了你的提示

## 记录你的提示

我们可以通过指定带有 `<prompt>` 语言标签的代码块来指定文档的哪部分是提示定义

``` python
@llm_prompt
def write_me_short_post(topic:str, platform:str="twitter", audience:str = "developers"):
    """
    这是在函数文档字符串中编写提示的好方法，并为开发者提供了额外文档。

    它需要是一个代码块，标记为 `<prompt>` 语言
    ```<prompt>
    为我写一个关于 {topic} 的帖子的简短标题，适用于 {platform} 平台。
    目标受众是 {audience}。
    （最多 15 个词）
    ```
    现在只有上面的代码块将用作提示，文档字符串的其余部分将用作开发者的描述。
    （它还有一个好处，IDE（如 VS code）将正确显示提示（不会尝试将其解析为 markdown，因此不会正确显示换行符））
    """
    return
```

## 聊天消息提示

对于聊天模型，将提示定义为一组消息模板非常有用... 以下是操作方法：

``` python
@llm_prompt
def simulate_conversation(human_input:str, agent_role:str="a pirate"):
    """
    ## 系统消息
     - 注意 `<prompt:_role_>` 标签内的 `:system` 后缀


    ```<prompt:system>
    你是一个 {agent_role} 黑客。你必须表现得像一个。
    你总是用代码回复，使用 python 或 javascript 代码块...
    例如：

    ... 不要回复其他任何内容.. 只回复代码 - 尊重你的角色。
    ```
    # 用户消息
    （我们使用 LLM 强制执行的真实角色 - GPT 支持 system、assistant、user）
    ``` <prompt:user>
    你好，你是谁
    ```
    一个回复：


    ``` <prompt:assistant>
    \``` python <<- 用 \ 转义内部代码块，这应该是提示的一部分
    def hello():
        print("Argh... hello you pesky pirate")
    \```
    ```

    我们也可以使用占位符添加一些历史记录
    ```<prompt:placeholder>
    {history}
    ```
    ```<prompt:user>
    {human_input}
    ```

    现在只有上面的代码块将用作提示，文档字符串的其余部分将用作开发者的描述。
    （它还有一个好处，IDE（如 VS code）将正确显示提示（不会尝试将其解析为 markdown，因此不会正确显示换行符））
    """
    pass

```

这里的角色是模型原生角色（chatGPT 的 assistant、user、system）



# 可选部分
- 你可以定义提示的整个部分为可选
- 如果部分中的任何输入缺失，则整个部分将不会被渲染

语法如下：

``` python
@llm_prompt
def prompt_with_optional_partials():
    """
    此文本将始终渲染，但是

    {? 此块内的任何内容仅在所有 {value}s 参数不为空（None | ""）时才会渲染   ?}

    你也可以将其放在单词之间
    这也将被渲染{? ，但是
        此块仅在 {this_value} 和 {this_value}
        不为空时才会渲染?} ！
    """
```
# 输出解析器

- llm_prompt 装饰器原生尝试根据输出类型检测最佳输出解析器。（如果未设置，它返回原始字符串）
- 列表、字典和 pydantic 输出也原生支持（自动）

``` python
# 此代码示例是完整的，应能直接运行

from langchain_decorators import llm_prompt

@llm_prompt
def write_name_suggestions(company_business:str, count:int)->list:
    """ 为 {company_business} 的公司写 {count} 个好的名称建议
    """
    pass

write_name_suggestions(company_business="sells cookies", count=5)
```
## 更复杂的结构

对于 dict / pydantic，你需要指定格式化指令...
这可能很繁琐，这就是为什么你可以让输出解析器根据模型（pydantic）为你生成指令

``` python
from langchain_decorators import llm_prompt
from pydantic import BaseModel, Field


class TheOutputStructureWeExpect(BaseModel):
    name:str = Field (description="公司名称")
    headline:str = Field( description="公司描述（用于着陆页）")
    employees:list[str] = Field(description="5-8 个假员工姓名及其职位")

@llm_prompt()
def fake_company_generator(company_business:str)->TheOutputStructureWeExpect:
    """ 生成一个 {company_business} 的假公司
    {FORMAT_INSTRUCTIONS}
    """
    return

company = fake_company_generator(company_business="sells cookies")

# 美观地打印格式化后的结果
print("公司名称: ",company.name)
print("公司标语: ",company.headline)
print("公司员工: ",company.employees)

```
# 将提示绑定到对象

``` python
from pydantic import BaseModel
from langchain_decorators import llm_prompt

class AssistantPersonality(BaseModel):
    assistant_name:str
    assistant_role:str
    field:str

    @property
    def a_property(self):
        return "whatever"

    def hello_world(self, function_kwarg:str=None):
        """
        我们可以在提示中引用任何 {field} 或 {a_property}... 并将其与方法中的 {function_kwarg} 结合
        """


    @llm_prompt
    def introduce_your_self(self)->str:
        """
        ``` <prompt:system>
        你是一个名为 {assistant_name} 的助手。
        你的角色是扮演 {assistant_role}
        ```
        ```<prompt:user>
        介绍你自己（少于 20 个词）
        ```
        """



personality = AssistantPersonality(assistant_name="John", assistant_role="a pirate")

print(personality.introduce_your_self(personality))
```
