>[GooseAI](https://goose.ai) 使部署 NLP 服务变得更简单、更易获取。
> `GooseAI` 是一个通过 API 提供的全托管推理服务。
> 与其他知名 API 功能相当，`GooseAI` 通过在代码中仅更改 2 行，
> 即可提供即插即用的解决方案，以业界最优的经济性提供开源语言模型服务。

## 安装与设置

- 使用 `pip install openai` 安装 Python SDK
- 从 [GooseAI 网站](https://goose.ai/) 获取您的 GooseAI API 密钥。
- 设置环境变量 (`GOOSEAI_API_KEY`)。

```python
import os
os.environ["GOOSEAI_API_KEY"] = "YOUR_API_KEY"
```


## 大语言模型

查看[使用示例](/oss/python/integrations/llms/gooseai)。

```python
from langchain_community.llms import GooseAI
```
