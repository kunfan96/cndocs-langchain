[Oxylabs](https://oxylabs.io/) 是一个市场领先的网络情报收集平台，由最高的商业、道德和合规标准驱动，使全球企业能够解锁数据驱动的洞察。

[langchain-oxylabs](https://pypi.org/project/langchain-oxylabs/) 实现了使大语言模型能够与 Oxylabs Web Scraper API 交互的工具。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-oxylabs
```

```bash uv
uv add langchain-oxylabs
```
</CodeGroup>
