title: "MindsDB 集成"
description: "使用 LangChain Python 与 MindsDB 集成。"
---

MindsDB 是一个基于企业数据定制人工智能的平台。借助 MindsDB 及其近 200 个与[数据源](https://docs.mindsdb.com/integrations/data-overview)和 [AI/ML 框架](https://docs.mindsdb.com/integrations/ai-overview)的集成，任何开发者都可以更快、更安全地利用其企业数据，为其特定目的定制人工智能。

通过 MindsDB，您可以将任何数据源连接到任何 AI/ML 模型，以实现和自动化人工智能驱动的应用程序。利用来自数据库、向量存储或应用程序的数据，实时部署、提供服务和微调模型。所有这些都可以使用开发者已经熟悉的通用工具来完成。

MindsDB 与 LangChain 集成，使用户能够：

- 在 MindsDB 中部署通过 LangChain 提供的模型，使其可被众多数据源访问。
- 在 MindsDB 中使用实时和动态数据微调通过 LangChain 提供的模型。
- 使用 LangChain 和 MindsDB 自动化人工智能工作流程。

请参阅[我们的文档](https://docs.mindsdb.com/integrations/ai-engines/langchain)，了解更多关于 MindsDB 与 LangChain 集成的信息并查看示例。
