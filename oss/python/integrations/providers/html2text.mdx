>[html2text](https://github.com/Alir3z4/html2text/) 是一个Python包，可将一页 `HTML` 转换为干净、易读的纯 `ASCII 文本`。

该ASCII文本恰好也是有效的 `Markdown`（一种文本转HTML格式）。

## 安装与设置

<CodeGroup>
```bash pip
pip install html2text
```

```bash uv
uv add html2text
```
</CodeGroup>

## 文档转换器

参见[使用示例](/oss/python/integrations/document_transformers/html2text)。

```python
from langchain_community.document_loaders import Html2TextTransformer
```
