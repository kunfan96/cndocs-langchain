>[Joplin](https://joplinapp.org/) 是一款开源笔记应用。它能捕捉你的想法，
> 并让你从任何设备安全地访问它们。


## 安装与设置

`Joplin API` 需要一个访问令牌。
你可以在 [Joplin REST API 文档](https://joplinapp.org/api/references/rest_api/) 中找到安装说明。


## 文档加载器

查看一个[使用示例](/oss/python/integrations/document_loaders/joplin)。

```python
from langchain_community.document_loaders import JoplinLoader
```
