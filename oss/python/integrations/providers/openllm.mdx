OpenLLM 让开发者能够通过**单个命令**将任何**开源大语言模型**作为**兼容 OpenAI 的 API** 端点运行。

- 🔬 为快速和生产环境使用而构建
- 🚂 支持 llama3、qwen2、gemma 等，以及许多**量化**版本 [完整列表](https://github.com/bentoml/openllm-models)
- ⛓️ 兼容 OpenAI 的 API
- 💬 内置类似 ChatGPT 的界面
- 🔥 通过最先进的推理后端加速 LLM 解码
- 🌥️ 为企业级云部署（Kubernetes、Docker 和 BentoCloud）做好准备

## 安装与设置

通过 PyPI 安装 OpenLLM 包：

<CodeGroup>
```bash pip
pip install openllm
```

```bash uv
uv add openllm
```
</CodeGroup>

## LLM

OpenLLM 支持广泛的开源大语言模型，也支持用户自己的微调模型。使用 `openllm model` 命令查看所有为 OpenLLM 预优化的可用模型。

## 封装器

有一个 OpenLLM 封装器，支持与运行中的 OpenLLM 服务器进行交互：

```python
from langchain_community.llms import OpenLLM
```

### OpenLLM 服务器封装器

此封装器支持与 OpenLLM 的兼容 OpenAI 的端点进行交互。

要运行模型，请执行：

```bash
openllm hello
```

封装器用法：

```python
from langchain_community.llms import OpenLLM

llm = OpenLLM(base_url="http://localhost:3000/v1", api_key="na")

llm("鸭子和鹅有什么区别？为什么加拿大有这么多鹅？")
```
