[Arcjet](https://arcjet.com) 脱敏集成允许您在将提示发送给 LLM 之前，从提示中脱敏敏感的用户信息。

Arcjet 脱敏完全在您自己的机器上运行，从不将数据发送到其他任何地方，确保一流的隐私和性能。

Arcjet 脱敏对象本身不是 LLM，而是包装了一个 LLM。它脱敏输入到它的文本，然后在返回之前对包装的 LLM 的输出进行反脱敏。

### 安装

安装 Arcjet 脱敏库：

<CodeGroup>
```bash npm
npm install @arcjet/redact
```
```bash yarn
yarn add @arcjet/redact
```
```bash pnpm
pnpm add @arcjet/redact
```
</CodeGroup>

并安装 LangChain Community：

<CodeGroup>
```bash npm
npm install @langchain/community @langchain/core
```
```bash yarn
yarn add @langchain/community @langchain/core
```
```bash pnpm
pnpm add @langchain/community @langchain/core
```
</CodeGroup>

现在您已准备好开始使用 Arcjet 脱敏来保护您的 LLM 调用！


## 用法

```typescript
import {
  ArcjetRedact,
  ArcjetSensitiveInfoType,
} from "@langchain/community/llms/arcjet";
import { OpenAI } from "@langchain/openai";

// 为 Arcjet 创建另一个 LLM 实例进行包装
const openai = new OpenAI({
  modelName: "gpt-3.5-turbo-instruct",
  openAIApiKey: process.env.OPENAI_API_KEY,
});

const arcjetRedactOptions = {
  // 指定一个 LLM，Arcjet 脱敏将在脱敏输入后调用它。
  llm: openai,

  // 指定应被脱敏的实体列表。
  // 如果未指定，则所有实体都将被脱敏。
  entities: ["email", "phone-number", "ip-address", "credit-card"] as ArcjetSensitiveInfoType[],

  // 您可以提供一个自定义检测函数来检测我们尚不支持的实体。
  // 它接收一个标记列表，您返回一个已识别类型的列表或 undefined。
  // 如果使用，您返回的 undefined 类型应添加到实体列表中。
  detect: (tokens: string[]) => {
    return tokens.map((t) => t === "some-sensitive-info" ? "custom-entity" : undefined)
  },

  // 提供给自定义检测函数的标记数量。默认为 1。
  // 可用于在检测自定义实体类型时提供额外的上下文。
  contextWindowSize: 1,

  // 这允许您在脱敏时提供自定义替换。请确保
  // 替换是唯一的，以便反脱敏能按预期工作。
  replace: (identifiedType: string) => {
    return identifiedType === "email" ? "redacted@example.com" : undefined;
  },

};

const arcjetRedact = new ArcjetRedact(arcjetRedactOptions);
const response = await arcjetRedact.invoke(
  "My email address is test@example.com, here is some-sensitive-info"
);
```
