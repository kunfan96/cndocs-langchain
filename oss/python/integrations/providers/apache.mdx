>[Apache 软件基金会（维基百科）](https://en.wikipedia.org/wiki/The_Apache_Software_Foundation)
> 是一个去中心化的开源开发者社区。他们生产的软件根据 Apache 许可证条款分发，这是一个用于自由和开源软件（FOSS）的宽松开源许可证。Apache 项目的特点是协作、基于共识的开发过程以及开放和务实的软件许可证，也就是说，它允许免费获得软件的开发者在非自由条款下重新分发它。每个项目由一个自选的技术专家团队管理，他们是项目的活跃贡献者。

## Apache AGE

>[Apache AGE](https://age.apache.org/) 是一个提供图数据库功能的 `PostgreSQL` 扩展。`AGE` 是 `A Graph Extension` 的缩写，灵感来源于 Bitnine 对 `PostgreSQL 10` 的分支 `AgensGraph`，这是一个多模态数据库。该项目的目标是创建一个可以同时处理关系型和图模型数据的单一存储，以便用户可以使用标准 ANSI SQL 以及图查询语言 `openCypher`。`Apache AGE` 存储的数据元素是节点、连接它们的边以及节点和边的属性。

了解更多关于 [与 Apache AGE 集成](/oss/python/integrations/graphs/apache_age) 的信息。

## Apache Cassandra

>[Apache Cassandra](https://cassandra.apache.org/) 是一个 NoSQL、面向行、高度可扩展且高可用的数据库。从 5.0 版本开始，该数据库附带了向量搜索功能。

了解更多关于 [与 Apache Cassandra 集成](/oss/python/integrations/providers/cassandra/) 的信息。

## Apache Doris

>[Apache Doris](https://doris.apache.org/) 是一个用于实时分析的现代数据仓库。它能在大规模实时数据上提供闪电般的分析速度。
>
>通常 `Apache Doris` 被归类为 OLAP，并且在 ClickBench（一个分析型数据库基准测试）中表现出色。由于它拥有超快的向量化执行引擎，它也可以用作快速的向量数据库。

了解更多关于 [与 Apache Doris 集成](/oss/python/integrations/providers/apache_doris/) 的信息。

## Apache Kafka

>[Apache Kafka](https://github.com/apache/kafka) 是一个分布式消息系统，用于发布和订阅记录流。


## Apache Spark

>[Apache Spark](https://spark.apache.org/) 是一个用于大规模数据处理的统一分析引擎。它提供了 Scala、Java、Python 和 R 的高级 API，以及一个支持通用计算图进行数据分析的优化引擎。它还支持丰富的高级工具，包括用于 SQL 和 DataFrame 的 `Spark SQL`、用于 pandas 工作负载的 `pandas API on Spark`、用于机器学习的 `MLlib`、用于图处理的 `GraphX` 以及用于流处理的 `Structured Streaming`。

了解更多关于 [与 Apache Spark 集成](/oss/python/integrations/providers/spark) 的信息。
