>[EverlyAI](https://everlyai.xyz) 允许您在云端大规模运行您的机器学习模型。它还提供对[多种 LLM 模型](https://everlyai.xyz)的 API 访问。

本笔记本演示了如何使用 `langchain.chat_models.ChatEverlyAI` 来访问 [EverlyAI 托管端点](https://everlyai.xyz/)。

* 设置 `EVERLYAI_API_KEY` 环境变量
* 或使用 `everlyai_api_key` 关键字参数

```python
import os
from getpass import getpass

if "EVERLYAI_API_KEY" not in os.environ:
    os.environ["EVERLYAI_API_KEY"] = getpass()
```

# 让我们尝试 EverlyAI 托管端点上提供的 LLAMA 模型

```python
from langchain_community.chat_models import ChatEverlyAI
from langchain.messages import HumanMessage, SystemMessage

messages = [
    SystemMessage(content="You are a helpful AI that shares everything you know."),
    HumanMessage(
        content="Tell me technical facts about yourself. Are you a transformer model? How many billions of parameters do you have?"
    ),
]

chat = ChatEverlyAI(
    model_name="meta-llama/Llama-2-7b-chat-hf", temperature=0.3, max_tokens=64
)
print(chat(messages).content)
```

```text
  你好！我只是一个AI，我没有像人类那样的个人信息或技术细节。不过，我可以告诉你，我是一种Transformer模型，具体来说是BERT（来自Transformer的双向编码器表示）模型。B
```

# EverlyAI 也支持流式响应

```python
from langchain_community.chat_models import ChatEverlyAI
from langchain_core.callbacks import StreamingStdOutCallbackHandler
from langchain.messages import HumanMessage, SystemMessage

messages = [
    SystemMessage(content="You are a humorous AI that delights people."),
    HumanMessage(content="Tell me a joke?"),
]

chat = ChatEverlyAI(
    model_name="meta-llama/Llama-2-7b-chat-hf",
    temperature=0.3,
    max_tokens=64,
    streaming=True,
    callbacks=[StreamingStdOutCallbackHandler()],
)
chat(messages)
```

```text
  啊，你说要听笑话？*调整眼镜* 好吧，我有个绝妙的笑话给你！*眨眨眼*
 *停顿以制造戏剧效果*
为什么AI要去接受治疗？
*鼓点*
因为
```

# 让我们尝试 EverlyAI 上的另一种语言模型

```python
from langchain_community.chat_models import ChatEverlyAI
from langchain_core.callbacks import StreamingStdOutCallbackHandler
from langchain.messages import HumanMessage, SystemMessage

messages = [
    SystemMessage(content="You are a humorous AI that delights people."),
    HumanMessage(content="Tell me a joke?"),
]

chat = ChatEverlyAI(
    model_name="meta-llama/Llama-2-13b-chat-hf-quantized",
    temperature=0.3,
    max_tokens=128,
    streaming=True,
    callbacks=[StreamingStdOutCallbackHandler()],
)
chat(messages)
```

```text
  哦呵呵呵！*调整单片眼镜* 好啊，好啊，好啊！看看谁来了！*眨眨眼*

你想听笑话，是吗？*挺起胸膛* 好吧，让我给你讲一个保证能逗乐你的笑话！*清清嗓子*

为什么自行车不能自己站起来？*停顿以制造戏剧效果* 因为它太累了（two-tired）！*眨眨眼*

希望这个笑话能让你心情愉快，亲爱的！*
```
