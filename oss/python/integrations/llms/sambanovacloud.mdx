本示例将介绍如何使用 LangChain 与 SambaNovaCloud 模型进行交互。

## 设置

### 凭证

要访问 ChatSambaNovaCloud 模型，您需要创建一个 [SambaNovaCloud 账户](https://cloud.sambanova.ai/)，获取 API 密钥并将其设置为 `SAMBANOVA_API_KEY` 环境变量：

```python
import getpass
import os

if "SAMBANOVA_API_KEY" not in os.environ:
    os.environ["SAMBANOVA_API_KEY"] = getpass.getpass()
```

### 安装

集成包位于 `langchain-community` 包中。我们还需要安装 [sseclient-py](https://pypi.org/project/sseclient-py/) 包，这是运行流式预测所必需的。

```python
pip install --quiet -U langchain-community sseclient-py
```

## 实例化

```python
from langchain_community.llms.sambanova import SambaNovaCloud

llm = SambaNovaCloud(
    model="Meta-Llama-3.3-70B-Instruct",
    max_tokens_to_generate=1000,
    temperature=0.01,
    # top_k = 50,
    # top_p = 1.0
)
```

## 调用

现在我们可以实例化模型对象并生成聊天补全：

```python
input_text = "Why should I use open source models?"

completion = llm.invoke(input_text)
completion
```

## 链式调用

我们可以将补全模型与提示模板链接起来，如下所示：

```python
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template("How to say {input} in {output_language}:\n")

chain = prompt | llm
chain.invoke(
    {
        "output_language": "German",
        "input": "I love programming.",
    }
)
```

```text
'"I love programming" 的德语翻译是：\n\n"Ich liebe das Programmieren."\n\n以下是句子的分解：\n\n* "Ich" 意思是 "我"\n* "liebe" 是动词 "to love"（爱）的第一人称单数形式（我爱）\n* "das" 是 "Programmieren"（编程）的定冠词\n* "Programmieren" 是动词 "to program"（编程）的不定式形式，但在此上下文中，它被用作名词来指代编程活动。\n\n因此，"Ich liebe das Programmieren" 是在德语中表达对编程热情的常用方式。'
```
