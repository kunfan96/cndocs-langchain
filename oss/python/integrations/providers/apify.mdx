>[Apify](https://apify.com) 是一个用于网页抓取和数据提取的云平台，
>它提供了一个包含一千多个名为 *Actors* 的现成应用的[生态系统](https://apify.com/store)，适用于各种抓取、爬取和提取用例。

## 概述

Apify 提供了对数千个用于网页抓取、数据提取和自动化的预构建工具（Actors）的访问。
该平台处理基础设施管理，让您能够专注于数据提取逻辑。

## 何时使用 Apify

- **访问数千个预构建的 Actors**，适用于各种平台（社交媒体、电子商务、搜索引擎等）
- **自定义网页抓取和自动化工作流**，超越简单搜索
- **灵活的 Actor 生态系统** – 运行来自 Apify Store 的任何 Actor

此集成使您能够在 `Apify` 平台上运行 Actors，并将其结果加载到 LangChain 中，从而为您的向量索引提供来自网络的文档和数据，例如，从包含文档、博客或知识库的网站生成答案。

## 安装与设置

- 使用以下命令安装 LangChain Apify Python 包：

<CodeGroup>
```bash pip
pip install langchain-apify
```

```bash uv
uv add langchain-apify
```
</CodeGroup>

- 获取您的 [Apify API 令牌](https://console.apify.com/account/integrations)，并将其设置为环境变量 (`APIFY_TOKEN`) 或在构造函数中作为 `apify_api_token` 传递。

## 工具

您可以使用 `ApifyActorsTool` 将 Apify Actors 与代理一起使用。

```python
from langchain_apify import ApifyActorsTool
```

有关示例用法以及使用 LangGraph 的工具调用代理的完整示例，请参阅[此笔记本](/oss/python/integrations/tools/apify_actors)和 [Apify LangGraph 代理 Actor 模板](https://apify.com/templates/python-langgraph)。

有关如何使用此工具的更多信息，请访问 [Apify 集成文档](https://docs.apify.com/platform/integrations/langgraph)。

## 封装器

您可以使用 `ApifyWrapper` 在 Apify 平台上运行 Actors。

```python
from langchain_apify import ApifyWrapper
```

有关如何使用此封装器的更多信息，请参阅 [Apify 集成文档](https://docs.apify.com/platform/integrations/langchain)。

## 用例

- **网页抓取**：从网站、社交媒体、电子商务网站提取数据
- **搜索引擎结果**：抓取 Google、Bing 和其他搜索引擎
- **数据收集**：为分析和机器学习管道收集结构化数据
- **内容聚合**：从多个来源收集内容用于 RAG 应用

## 文档加载器

您也可以使用我们的 `ApifyDatasetLoader` 从 Apify 数据集中获取数据。

```python
from langchain_apify import ApifyDatasetLoader
```

有关此加载器的更详细演练，请参阅[此笔记本](/oss/python/integrations/document_loaders/apify_dataset)。

## 定价

Apify 使用按使用付费或按事件付费的定价模式，并提供免费套餐。定价因 Actor 而异：

- 一些 Actors 是免费的（您只需支付平台计算单元费用）
- 其他 Actors 对结果或事件收费
- **按事件付费 (PPE) 定价**：许多 Actors 支持 [PPE 定价](https://docs.apify.com/platform/actors/publishing/monetize/pay-per-event)，当您希望在代理部署中获得可预测的、基于使用量的成本时，这非常有用
- 详情请参阅 [Apify 定价](https://apify.com/pricing)

此集成的源代码可在 [LangChain Apify 仓库](https://github.com/apify/langchain-apify) 中找到。

## MCP 服务器

不确定使用哪个 Actor 或它需要什么参数？
Apify 提供了一个 [MCP（模型上下文协议）服务器](https://mcp.apify.com)，帮助您发现可用的 Actors，探索其输入模式，并了解参数要求。

通过 HTTP 连接到 Apify MCP 服务器时，请在请求头中包含您的 Apify 令牌：

```text
Authorization: Bearer <APIFY_TOKEN>
```
