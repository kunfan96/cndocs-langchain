[Box](https://box.com) 是智能内容云，一个单一平台，使组织能够促进协作、管理整个内容生命周期、保护关键内容，并通过企业 AI 转变业务工作流程。Box 成立于 2005 年，为全球领先组织简化工作，包括阿斯利康、JLL、摩根士丹利和 Nationwide。

在此包中，我们提供了多种将 Box 内容纳入 AI 工作流程的方法。

<CodeGroup>
```bash pip
pip install -U langchain-box
```

```bash uv

```
</CodeGroup>

# langchain-box

此包包含 LangChain 与 Box 的集成。有关 Box 的更多信息，请查看我们的[开发者文档](https://developer.box.com)。

## 前提条件

要与 Box 集成，您需要一些东西：

* 一个 Box 实例 — 如果您不是当前 Box 客户，请注册一个[免费开发者账户](https://account.box.com/signup/n/developer#ty9l3)。
* 一个 Box 应用 — 更多关于如何[创建应用](https://developer.box.com/guides/getting-started/first-application/)的信息
* 您的应用在 Box 实例中获得批准 — 这由您的管理员完成。好消息是，如果您使用的是免费开发者账户，您就是管理员。[授权您的应用](https://developer.box.com/guides/authorization/custom-app-approval/#manual-approval)

## 身份验证

`box-langchain` 包为身份验证提供了一些灵活性。最基本的身份验证方法是使用开发者令牌。这可以在 [Box 开发者控制台](https://account.box.com/developers/console)的配置屏幕上找到。此令牌故意设置为短期有效（1 小时），旨在用于开发。使用此令牌，您可以将其添加到环境变量 `BOX_DEVELOPER_TOKEN` 中，可以直接传递给加载器，或者使用 `BoxAuth` 身份验证辅助类。

我们将在下一节中介绍直接将其传递给加载器的方法。

### BoxAuth 辅助类

`BoxAuth` 支持以下身份验证方法：

* 令牌 — 开发者令牌或通过 Box SDK 生成的任何令牌
* 使用服务账户的 JWT
* 使用指定用户的 JWT
* 使用服务账户的 CCG
* 使用指定用户的 CCG

<Note>
**如果使用 JWT 身份验证，您需要在生成公钥/私钥对后从 Box 开发者控制台下载配置。**

将此文件放在您的应用程序目录结构中的某个位置。使用 `BoxAuth` 辅助类时，您将使用此文件的路径。
</Note>

有关更多信息，请了解如何[设置 Box 应用](https://developer.box.com/guides/getting-started/first-application/)，并查看 [Box 身份验证指南](https://developer.box.com/guides/authentication/select/)以了解更多关于我们的不同身份验证选项。

示例：

**令牌**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.TOKEN,
    box_developer_token=box_developer_token
)

loader = BoxLoader(
    box_auth=auth,
    ...
)
```

**使用服务账户的 JWT**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.JWT,
    box_jwt_path=box_jwt_path
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**使用指定用户的 JWT**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.JWT,
    box_jwt_path=box_jwt_path,
    box_user_id=box_user_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**使用服务账户的 CCG**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.CCG,
    box_client_id=box_client_id,
    box_client_secret=box_client_secret,
    box_enterprise_id=box_enterprise_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**使用指定用户的 CCG**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.CCG,
    box_client_id=box_client_id,
    box_client_secret=box_client_secret,
    box_user_id=box_user_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

如果您希望使用 OAuth2 的 authorization_code 流程，请使用 `BoxAuthType.TOKEN` 以及您已获取的令牌。
