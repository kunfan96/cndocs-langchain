支持 ReAct 模式的 Google 图书工具，允许您搜索 Google 图书 API。Google 图书是世界上最大的以策展方式追踪书籍的 API。它拥有超过 4000 万条记录，可以为用户提供大量数据。

### 工具功能

目前该工具具有以下功能：

- 使用关键词搜索从 Google 图书 API 收集相关信息
- 将信息格式化为可读的输出，并将结果返回给代理

## 设置

确保已安装 `langchain-community`。

```python
pip install -qU  langchain-community
```

### 凭证

您需要一个来自 Google 图书的 API 密钥。您可以通过访问并遵循 [https://developers.google.com/books/docs/v1/using#APIKey](https://developers.google.com/books/docs/v1/using#APIKey) 上的步骤来获取。

然后，您需要将环境变量 `GOOGLE_BOOKS_API_KEY` 设置为您的 Google 图书 API 密钥。

## 实例化

要实例化该工具，请导入 Google 图书工具并设置您的凭证。

```python
import os

from langchain_community.tools.google_books import GoogleBooksQueryRun
from langchain_community.utilities.google_books import GoogleBooksAPIWrapper

os.environ["GOOGLE_BOOKS_API_KEY"] = "<your Google Books API key>"
tool = GoogleBooksQueryRun(api_wrapper=GoogleBooksAPIWrapper())
```

## 调用

您可以通过调用 `run` 方法来调用该工具。

```python
tool.run("ai")
```

### [使用 ToolCall 调用](/oss/python/langchain/tools)

请参阅下面的工具调用示例。

```python
import getpass
import os

from langchain_community.tools.google_books import GoogleBooksQueryRun
from langchain_community.utilities.google_books import GoogleBooksAPIWrapper
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI

os.environ["OPENAI_API_KEY"] = getpass.getpass()
os.environ["GOOGLE_BOOKS_API_KEY"] = "<your Google Books API key>"

tool = GoogleBooksQueryRun(api_wrapper=GoogleBooksAPIWrapper())
llm = ChatOpenAI(model="gpt-5.4-mini")
prompt = PromptTemplate.from_template(
    "Return the keyword, and only the keyword, that the user is looking for from this text: {text}"
)


def suggest_books(query):
    chain = prompt | llm | StrOutputParser()
    keyword = chain.invoke({"text": query})
    return tool.run(keyword)


suggestions = suggest_books("I need some information on AI")
print(suggestions)
```

## 链式调用

请参阅下面的链式调用示例。

```python
import getpass
import os

from langchain_classic import hub
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_community.tools.google_books import GoogleBooksQueryRun
from langchain_community.utilities.google_books import GoogleBooksAPIWrapper
from langchain_openai import ChatOpenAI

os.environ["OPENAI_API_KEY"] = getpass.getpass()
os.environ["GOOGLE_BOOKS_API_KEY"] = "<your Google Books API key>"

tool = GoogleBooksQueryRun(api_wrapper=GoogleBooksAPIWrapper())
llm = ChatOpenAI(model="gpt-5.4-mini")

instructions = """You are a book suggesting assistant."""
base_prompt = hub.pull("langchain-ai/openai-functions-template")
prompt = base_prompt.partial(instructions=instructions)

tools = [tool]
agent = create_tool_calling_agent(llm, tools, prompt)
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,
)

agent_executor.invoke({"input": "Can you recommend me some books related to ai?"})
```
