## langsmith-0.14.0

LangSmith 自托管 v0.14 将 **Polly**（我们用于跟踪和运行的 AI 助手）引入自托管，将 **ABAC 和审计日志** 正式发布（默认开启），并默认启用 **LLM Auth Proxy**，支持 URL 允许列表和更丰富的 JWT 声明。管理员获得**统一的模型配置**，在代理构建器、Polly、洞察、Playground 和评估器之间共享，以及细粒度的 **Prompt Owners**，用于锁定谁可以提升或删除单个提示。评估器获得**多模态支持**，工作区现在可以为跟踪项目设置**成本警报**。Playground 模型支持扩展（通过 Vertex AI 的 Anthropic、自定义 Azure 模型、Bedrock 推理配置文件、Gemini 3.1 Pro、GPT-5.3 / 5.4、Baseten + GLM-5），新的代理工具和触发器适用于 Google Sheets & Docs、Outlook、Teams 和 Salesforce SOQL。在基础设施方面，v0.14 为 blob 存储添加了 **GCS Workload Identity** 支持，将 **Valkey** 作为 Redis 的直接替代品，以及用于更安全部署的预升级迁移钩子。

请遵循[升级说明](/langsmith/self-host-upgrades)以访问所有功能。要预约 LangChain 支持进行升级，请联系 `support@langchain.dev`。

### 破坏性变更

- 修复了 `host-backend` 未获取 `commonEnv` 的问题。这可能导致需要删除的重复环境变量。

### 基础设施变更

- 迁移现在作为镜像版本推出前的 `Pre-upgrade` 钩子运行。这将防止迁移失败时出现问题。
- **GCS Workload Identity 支持** — 使用云原生工作负载身份而不是长期凭据进行 GCS blob 存储身份验证。
- **Valkey 支持** — Valkey 现在可用作 Redis 的直接替代品。

### 新功能

- **自托管中的 Polly** — 我们用于理解跟踪、运行和评估器反馈的 AI 助手现在在自托管中可用。
- **ABAC 和审计日志正式发布** — 基于属性的访问控制和审计日志在自托管部署中默认启用。
- **LLM Auth Proxy 默认开启** — URL 允许列表防止凭据转发到非预期主机，JWT 现在携带 `organization_name` 和 `workspace_name` 声明。
- **统一的模型配置** — 代理构建器、Polly、洞察、Playground 和评估器现在共享一组模型配置，工作区管理员可控制所有 AI 功能的模型访问。
- **Prompt Owners** — 指定一组特定用户，拥有细粒度权限来提升或删除单个提示，而无需授予更广泛的组织访问权限。
- **多模态评估器** — 直接将附件和 base64 内容（图像、音频、PDF）传递给评估器。
- **跟踪项目上的成本警报** — 在现有的 LangSmith 警报之外，为跟踪项目级别成本设置警报。
- **扩展的 Playground 模型支持** — 通过 Vertex AI 的 Anthropic、自定义 Azure 模型、Bedrock 推理配置文件和可配置的基础 URL、Gemini 3.1 Pro、GPT-5.3 / 5.4（现在是默认值）以及 Baseten + GLM-5。
- **新的代理工具和触发器** — Google Sheets 和 Docs、Outlook 邮件和日历、Microsoft Teams、Salesforce SOQL、带有刷新令牌的 Gmail OAuth v2 以及 Outlook 触发器。
- **洞察增强** — 计划的洞察报告、随时间变化的趋势类别、分析中的完整反馈评论，以及更低的最小作业间隔（6 小时 → 1 小时）。
- **标注和审查升级** — 每个队列所需的审阅者、遵守 `reviewer_access_mode` 的成对队列、“分配给我”过滤器、每个标注者的 CSV 导出以及批量表操作。
- **Prompt Hub 和工具注册表** — 提交标签搜索、模板创建中的模型选择、工作区范围的工具注册表 API 和私有注册表 UI。
- **评估器工作流改进** — 预构建的 LLM 评估器默认使用严格的结构化输出，评估器支持标记和重用，重试不再丢失分数，新的 API 可以编程方式运行 playground 实验。
- **自定义 iframe 输出渲染器** — 在实验和跟踪视图中拖动调整 HTML 图表输出的大小。
- **线程和收件箱 UX** — 自动生成的线程标题、重新设计的线程中的运行详情、会话级反馈统计、键盘快捷键，以及过滤掉内部辅助线程。

### 管理员变更

- **细粒度使用情况报告** — 细粒度的可计费使用情况 API，允许您检索按工作区、项目、用户或 API 密钥细分的详细跟踪使用情况数据。
</Update>
