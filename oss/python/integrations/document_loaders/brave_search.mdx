>[Brave搜索](https://en.wikipedia.org/wiki/Brave_Search)是由Brave Software开发的搜索引擎。
>
> - `Brave搜索`使用其自有的网络索引。截至2022年5月，该索引覆盖了超过100亿个页面，并用于提供92%的搜索结果，无需依赖任何第三方，其余部分则通过服务器端从Bing API检索，或（在用户选择加入的情况下）客户端从Google检索。据Brave称，该索引被“有意保持得比Google或Bing的索引小”，以帮助避免垃圾信息和其他低质量内容，但缺点是“Brave搜索在处理长尾查询方面尚未达到Google的水平。”
>- `Brave搜索高级版`：截至2023年4月，Brave搜索是一个无广告的网站，但它最终将切换到一个包含广告的新模式，高级用户将获得无广告体验。默认情况下不会从其用户收集包括IP地址在内的用户数据。选择加入数据收集将需要高级账户。

## 安装与设置

要访问Brave搜索API，您需要[创建一个账户并获取API密钥](https://api.search.brave.com/app/dashboard)。

```python
api_key = "..."
```

```python
from langchain_community.document_loaders import BraveSearchLoader
```

## 示例

```python
loader = BraveSearchLoader(
    query="obama middle name", api_key=api_key, search_kwargs={"count": 3}
)
docs = loader.load()
len(docs)
```

```text
3
```
