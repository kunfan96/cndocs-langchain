>[GitBook](https://docs.gitbook.com/) 是一个现代化的文档平台，团队可以在此记录从产品到内部知识库和 API 的所有内容。

## 安装与设置

无需进行任何特殊设置。

## 文档加载器

查看[使用示例](/oss/python/integrations/document_loaders/gitbook)。

```python
from langchain_community.document_loaders import GitbookLoader
```
