**Dappier：以动态、实时数据模型驱动 AI**

Dappier 提供了一个前沿平台，让开发者能够即时访问涵盖新闻、娱乐、金融、市场数据、天气等领域的广泛实时数据模型。借助我们预训练的数据模型，您可以增强 AI 应用程序的能力，确保它们提供精确、最新的响应，并最大限度地减少不准确性。

Dappier 数据模型帮助您利用来自世界领先品牌的可信、最新内容构建下一代 LLM 应用。通过一个简单的 API，释放您的创造力，用可操作的专有数据增强任何 GPT 应用或 AI 工作流。使用来自可信来源的专有数据来增强您的 AI，是确保获得事实准确、最新响应并减少幻觉的最佳方式，无论问题是什么。

为开发者，由开发者打造
Dappier 以开发者为中心设计，简化了从数据集成到变现的旅程，为部署和从您的 AI 模型中获利提供了清晰、直接的路径。在 **[dappier.com/](https://dappier.com/)** 体验新互联网的未来变现基础设施。

本示例介绍如何使用 LangChain 与 Dappier AI 模型进行交互。

-----------------------------------------------------------------------------------

要使用我们的 Dappier AI 数据模型之一，您需要一个 API 密钥。请访问 Dappier 平台 ([platform.dappier.com/](https://platform.dappier.com/)) 登录并在您的个人资料中创建一个 API 密钥。

您可以在 API 参考文档中找到更多详情：[docs.dappier.com/introduction](https://docs.dappier.com/introduction)

要使用我们的 Dappier 聊天模型，您可以在初始化类时通过名为 `dappier_api_key` 的参数直接传递密钥，或将其设置为环境变量。

```bash
export DAPPIER_API_KEY="..."
```

```python
from langchain_community.chat_models.dappier import ChatDappierAI
from langchain.messages import HumanMessage
```

```python
chat = ChatDappierAI(
    dappier_endpoint="https://api.dappier.com/app/datamodelconversation",
    dappier_model="dm_01hpsxyfm2fwdt2zet9cg6fdxt",
    dappier_api_key="...",
)
```

```python
messages = [HumanMessage(content="Who won the super bowl in 2024?")]
chat.invoke(messages)
```
