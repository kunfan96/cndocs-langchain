LangSmith 根据您的[套餐](/langsmith/pricing-plans)和[部署类型](/langsmith/platform-setup)，提供了多种查看[组织](/langsmith/administration-overview)使用情况的方式。本页说明了可用的数据、每个指标的含义，以及适用于[自托管](/langsmith/self-hosted)部署的限制。

## 使用情况视图

| 视图 | 查看位置 | 可见人员 | 套餐可用性 |
|------|---------|---------|-----------|
| [使用情况图表](#usage-graph) |**企业版**：设置 > 使用情况 > 使用情况图表<br></br>**自助服务**：设置 > 账单 > 使用情况图表 | 所有组织成员 | 所有套餐 |
| [详细使用情况](#granular-usage) | **企业版**：设置 > 使用情况 > 详细使用情况<br></br>**自助服务**：设置 > 账单 > 详细使用情况 | 所有组织成员 | 所有套餐 |
| [合同消耗情况](#contract-burndown) | **企业版**：设置 > 使用情况 > 合同使用情况<br></br>**自助服务**：设置 > 账单 > 合同使用情况 | 仅组织管理员 (`organization:manage`) | 仅企业版 |
| [发票](#invoices) | 设置 > 账单 > 发票 | 所有组织成员 | 仅自助服务云套餐 |

## 使用情况图表

使用情况图表显示您组织的聚合跟踪消耗量，按工作区细分。它涵盖当前计费周期，不显示支出——有关支出信息，请参阅发票。

导航至 **设置** → **账单和使用情况** → **使用情况图表**。

### 可计费指标

| 指标 | 计数内容 |
|------|---------|
| **LangSmith 跟踪（基础费用）** | 在计费周期内发送到 LangSmith 的每个跟踪，无论数据保留层级如何。 |
| **LangSmith 跟踪（扩展数据保留升级）** | 升级到扩展保留的跟踪（默认为 400 天，[企业客户可自定义](/langsmith/data-purging-compliance#customize-extended-retention-policy)）。这些费用在基础费用之外额外收取。 |
| **LangSmith 部署运行次数** | 已部署的 LangGraph 代理的端到端调用。有关定价详情，请参阅 [LangSmith 部署计费](/langsmith/billing#langsmith-deployment-billing)。 |
| **LangSmith Fleet 运行次数** | [Fleet](/langsmith/fleet) 代理的端到端调用。云托管和自托管部署分别跟踪。 |
| **LangSmith 部署节点执行次数** | 已部署代理中各个 LangGraph 节点的执行次数。已部署代理图中的每个步骤计为一次节点执行。云托管和自托管部署分别跟踪。 |

有关跟踪保留层级的更多详细信息，请参阅[数据保留](/langsmith/administration-overview#data-retention)。

<Note>
使用情况图表将术语 `tenant_id` 与工作区 ID 互换使用。
</Note>

## 合同消耗情况

具有预付承诺的企业客户可以查看其合同已消耗的额度。

导航至 **设置** → **使用情况配置** → **合同使用情况**。

此视图显示：

- **使用情况摘要**：总使用量、总积分以及任何超额部分。当使用量超过您的总预付承诺时，就会发生超额。
- **承诺进度条**：每个承诺的可视化指示器，显示已消耗百分比以及已用与剩余的金额。合同可以有多个承诺，适用于不同的时间段（例如，多年合同的第一年和第二年）或不同的产品。
- **月度使用情况图表**：柱状图，显示您合同期内每个月的使用量。
- **产品费率**：您有权使用的产品及其定价的表格。

<Note>
合同消耗情况需要 [`organization:manage` 权限](/langsmith/organization-workspace-operations)，并且仅适用于具有预付承诺的企业客户。
</Note>

## 发票

发票仅在**自助服务云套餐**上可用。企业云组织有一个单独的使用情况视图来跟踪支出。

导航至 **设置** → **账单和使用情况** → **发票**，查看您的使用情况如何转化为支出。显示的第一张发票是您当月发票的草稿，反映了您迄今为止的持续支出。

## 详细使用情况

详细使用情况为您提供按您选择的维度（工作区、项目、用户或 API 密钥）在您选择的时间范围内细分的跟踪计数。这对于内部计费、识别高使用量团队或审计跟踪活动非常有用。

导航至 **设置** → **账单和使用情况** → **详细使用情况**，或使用[详细使用情况 API](/langsmith/granular-usage)。

### 此处“跟踪”的含义

详细使用情况视图计算**跟踪**：根级运行及其所有子跨度作为一个单一单元计算。这是用于[计费](/langsmith/billing)的相同单位。它不单独计算各个跨度、令牌或模型调用。

### 使用情况记录时间

详细使用情况按**插入时间**（跟踪被 LangSmith 接收和存储的时间）记录跟踪，而不是按其在应用程序中运行的时间。实际上，这种差异通常可以忽略不计，但延迟发送的跟踪（例如，缓冲的 SDK 上传）可能会出现在比预期更晚的时间段中。

有关分组选项、时间段大小和 API 参考，请参阅[详细可计费使用情况](/langsmith/granular-usage)。

## 自托管限制

[自托管](/langsmith/self-hosted) LangSmith [部署](/langsmith/deployment)与[云](/langsmith/cloud)相比，由于计费基础设施的差异，可用的使用情况视图有所不同。

| **功能** | **自托管可用性** |
|---------|--------------------------|
| 详细使用情况（跟踪归因） | 通过功能标志或版本 ≥ 0.13.12 可用 |
| 使用情况图表（聚合跟踪） | 在 Helm chart 0.9.5 及更高版本上可用 |
| 合同消耗情况 | 启用 Beacon 回传时可用 |
| 发票和支付管理 | 不可用（计费在 LangSmith 外部处理） |

### 自托管上的详细使用情况

详细使用情况在自托管部署上可用，但需要明确选择启用：

- 在 **LangSmith 0.13.12 及更高版本**上，默认启用详细使用情况收集。
- 在**早期版本**上，通过设置以下两个环境变量来启用：

    ```env
    DEFAULT_ORG_FEATURE_ENABLE_GRANULAR_USAGE_REPORTING=true
    GRANULAR_USAGE_TABLE_ENABLED=true
    ```

<Warning>
数据收集从功能启用的那一刻开始。不会回填启用前的历史使用情况数据。在选择何时启用此功能时，请做好相应规划。
</Warning>

### 自托管上的聚合使用情况

使用情况图表在运行 Helm chart 0.9.5 或更高版本的自托管部署上可用。LangSmith 自动生成并同步组织使用情况图表，可在 **设置** → **使用情况和账单** → **使用情况图表** 下找到：

- **按工作区使用情况**：每个工作区的跟踪计数（根运行）
- **组织使用情况**：整个组织的总跟踪计数

图表每 5 分钟刷新一次以包含新的工作区，并且不可编辑。

有关以编程方式访问跟踪计数，请参阅[查看组织中的跟踪计数](/langsmith/self-host-organization-charts)。
