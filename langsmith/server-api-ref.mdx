Agent Server API 参考文档可在每个[部署](/langsmith/deployment)的 `/docs` 端点（例如 `http://localhost:8124/docs`）中获取。

您可以在侧边栏的 **Agent Server API** 部分浏览完整的 API 参考，或查看下方的端点分组：

- [助手](/langsmith/agent-server-api/assistants) - 图的已配置实例
- [线程](/langsmith/agent-server-api/threads) - 一组运行的累积输出
- [线程运行](/langsmith/agent-server-api/thread-runs) - 在线程上对图/助手的调用
- [无状态运行](/langsmith/agent-server-api/stateless-runs) - 无状态持久化的调用
- [定时任务](/langsmith/agent-server-api/crons) - 按计划定期运行
- [存储](/langsmith/agent-server-api/store) - 用于长期记忆的持久化键值存储
- [A2A](/langsmith/agent-server-api/a2a) - Agent-to-Agent 协议端点
- [MCP](/langsmith/agent-server-api/mcp) - 模型上下文协议端点
- [系统](/langsmith/agent-server-api/system) - 健康检查和服务器信息

## 认证

对于部署到 LangSmith 的情况，需要进行认证。在每次向 Agent Server 发送请求时，请传递 `X-Api-Key` 请求头。该请求头的值应设置为部署 Agent Server 的组织的有效 LangSmith API 密钥。

`curl` 命令示例：

```shell
curl --request POST \
  --url http://localhost:8124/assistants/search \
  --header 'Content-Type: application/json' \
  --header 'X-Api-Key: LANGSMITH_API_KEY' \
  --data '{
  "metadata": {},
  "limit": 10,
  "offset": 0
}'
```
