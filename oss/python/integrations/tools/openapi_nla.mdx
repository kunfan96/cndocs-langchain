`自然语言API`工具包（`NLAToolkits`）允许LangChain代理高效地规划和组合跨端点的调用。

本笔记本演示了`Speak`、`Klarna`和`Spoonacluar` API的示例组合。

### 首先，导入依赖项并加载LLM

```python
from langchain.agents import create_agent
from langchain_community.agent_toolkits import NLAToolkit
from langchain_community.utilities import Requests
from langchain_openai import OpenAI
```

```python
# 选择要使用的LLM。这里，我们使用gpt-3.5-turbo-instruct
llm = OpenAI(
    temperature=0, max_tokens=700, model_name="gpt-3.5-turbo-instruct"
)  # 您可以在此处切换不同的核心LLM。
```

### 接下来，加载自然语言API工具包

```python
speak_toolkit = NLAToolkit.from_llm_and_url(llm, "https://api.speak.com/openapi.yaml")
klarna_toolkit = NLAToolkit.from_llm_and_url(
    llm, "https://www.klarna.com/us/shopping/public/openai/v0/api-docs/"
)
```

### 创建代理

```python
# 稍微调整默认代理的指令
openapi_format_instructions = """使用以下格式：

问题：您必须回答的输入问题
思考：您应该始终思考要做什么
操作：要采取的操作，应为[{tool_names}]之一
操作输入：指示AI操作代表的内容。
观察：代理的响应
...（此思考/操作/操作输入/观察可以重复N次）
思考：我现在知道最终答案了。用户看不到我的任何观察、API响应、链接或工具。
最终答案：对原始输入问题的最终答案，包含适当数量的细节

在回复最终答案时，请记住您回复的人无法看到您的任何思考/操作/操作输入/观察，因此如果有任何相关信息，您需要在回复中明确包含它们。"""
```

```python
natural_language_tools = speak_toolkit.get_tools() + klarna_toolkit.get_tools()
mrkl = create_agent(
    model=llm,
    tools=natural_language_tools,
    system_prompt=openapi_format_instructions,
)
```

```python
mrkl.invoke(
    {"input": "我为我的意大利语课程举办年终派对，需要为它购买一些意大利服装"}
)
```

### 使用认证并添加更多端点

某些端点可能需要通过访问令牌等方式进行用户认证。这里我们展示如何通过`Requests`包装对象传递认证信息。

由于每个NLATool都为其包装的API提供了一个简洁的自然语言接口，因此顶层对话代理在整合每个端点以满足用户请求时工作更轻松。

**添加Spoonacular端点。**

1. 前往[Spoonacular API控制台](https://spoonacular.com/food-api/console#Profile)并创建一个免费账户。
2. 点击`Profile`并复制您的API密钥。

```python
spoonacular_api_key = ""  # 从API控制台复制
```

```python
requests = Requests(headers={"x-api-key": spoonacular_api_key})
spoonacular_toolkit = NLAToolkit.from_llm_and_url(
    llm,
    "https://spoonacular.com/application/frontend/downloads/spoonacular-openapi-3.json",
    requests=requests,
    max_text_length=1800,  # 如果您想截断响应文本
)
```
