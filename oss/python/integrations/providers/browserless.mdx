>[Browserless](https://www.browserless.io/docs/start) 是一项允许您在云端运行无头 Chrome 实例的服务。这是一种无需担心管理自身基础设施即可大规模运行基于浏览器的自动化的绝佳方式。

## 安装与设置

从 [Browserless 定价页面](https://www.browserless.io/pricing/) 获取 API 密钥。

## 文档加载器

参见[使用示例](/oss/python/integrations/document_loaders/browserless)。

```python
from langchain_community.document_loaders import BrowserlessLoader
```
