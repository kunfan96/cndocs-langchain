>[Bilibili](https://www.bilibili.com/) 是中国最受欢迎的长视频网站之一。

此加载器利用 [bilibili-api](https://github.com/Nemo2011/bilibili-api) 从 `Bilibili` 视频中检索文本转录。要有效使用此加载器，必须拥有 `sessdata`、`bili_jct` 和 `buvid3` cookie 参数。可以通过登录 [Bilibili](https://www.bilibili.com/)，然后从浏览器的开发者工具中提取 `sessdata`、`bili_jct` 和 `buvid3` 的值来获取这些参数。

如果您选择将 cookie 参数留空，加载器仍然可以工作，但它将仅检索视频信息作为元数据，而无法获取转录。

有关获取这些凭证的详细说明，请参阅 [bilibili-api 凭证指南](https://nemo2011.github.io/bilibili-api/#/get-credential)。

BiliBiliLoader 提供了一个用户友好的界面，可以轻松访问 Bilibili 上所需视频内容的转录，对于希望分析或利用这些媒体数据的人来说，它是一个宝贵的工具。

```python
pip install -qU  bilibili-api-python
```

```python
from langchain_community.document_loaders import BiliBiliLoader
```

```python
SESSDATA = "<your sessdata>"
BUVID3 = "<your buvids>"
BILI_JCT = "<your bili_jct>"
```

```python
loader = BiliBiliLoader(
    [
        "https://www.bilibili.com/video/BV1g84y1R7oE/",
    ],
    sessdata=SESSDATA,
    bili_jct=BILI_JCT,
    buvid3=BUVID3,
)
```

```python
docs = loader.load()
```
