[Nimble](https://www.nimbleway.com/) 通过一个搜索 API 提供实时网络数据访问，该 API 浏览的是实时网络，而非依赖预构建的索引。与传统的搜索 API 不同，Nimble 使用无头浏览器实时导航网站——处理 JavaScript 渲染、动态内容、分页和复杂的多步骤导航流程。

**关键技术能力：**

- **实时网络浏览**：实时访问当前网络内容，而非缓存索引
- **JavaScript 渲染**：处理现代单页应用、延迟加载和客户端渲染
- **灵活模式**：快速模式用于 SERP 数据，或深度模式用于完整内容提取
- **AI 摘要**：可选的 LLM 生成的答案，与原始搜索结果并列
- **生产就绪**：为规模化构建，支持异步和全面的错误处理

更多信息，请访问 [nimbleway.com](https://www.nimbleway.com/) 或查阅 [Nimble 官方文档](https://docs.nimbleway.com/)。

## 安装与设置

Nimble 集成存在于其独立的合作伙伴包中。你可以通过以下方式安装：

<CodeGroup>
```bash pip
pip install -U langchain-nimble
```
```bash uv
uv add langchain-nimble
```
</CodeGroup>

要使用该包，你需要将 `NIMBLE_API_KEY` 环境变量设置为你的 Nimble API 密钥。你可以通过在 [Nimble](https://www.nimbleway.com/) 注册来获取 API 密钥。
