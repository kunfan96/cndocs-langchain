title: 代理身份

代理身份控制代理在与应用和服务交互时使用谁的[凭据](/langsmith/fleet/workspace-admin)。

<Warning>
一旦设置了代理身份，就无法更改。
</Warning>

## 固定凭据（"Claws"）

代理始终使用相同的 API 密钥和 OAuth 令牌进行身份验证，无论与之交互的是谁。

在以下情况下使用固定凭据：

- 代理作为共享服务运行（例如，团队 Slack 机器人或每日简报代理）。
- 您希望为所有用户使用单一的已认证账户集合。
- 代理需要在[频道](/langsmith/fleet/channels)或[计划](/langsmith/fleet/schedules)上运行，这些场景需要固定凭据。

使用固定凭据时，代理执行的所有操作（发送电子邮件、发布消息、读取日历）都使用代理所有者在设置过程中连接的账户。

## 用户凭据（"Assistants"）

代理使用与之交互的用户的 API 密钥和 OAuth 令牌进行身份验证，代表用户行事。

在以下情况下使用用户凭据：

- 每个用户应通过自己的账户进行操作（例如，一个从用户自己的收件箱读取和发送邮件的电子邮件助手）。
- 您需要按用户进行访问控制，以便代理只能看到该用户有权查看的内容。
- 审计跟踪需要反映哪个用户执行了每个操作。

使用用户凭据时，每个用户在首次与代理交互时会单独进行身份验证。代理在该用户的线程中执行所有后续操作时，都会使用该用户的令牌。

## 设置代理身份

要设置代理的身份：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，导航到您要编辑的代理。
1. 点击右上角的 <Icon icon="pencil" /> **编辑**。
1. 点击 **设置身份** 并选择您要使用的身份。
1. 点击 **保存**。
