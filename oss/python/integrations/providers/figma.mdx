>[Figma](https://www.figma.com/) 是一个用于界面设计的协作式网络应用程序。

## 安装与设置

Figma API 需要一个 `访问令牌`、`节点 ID` 和一个 `文件密钥`。

`文件密钥` 可以从 URL 中提取。  https://www.figma.com/file/\{filekey\}/sampleFilename

`节点 ID` 也可在 URL 中找到。点击任意元素并查找 `?node-id=\{node_id\}` 参数。

`访问令牌` [说明](https://help.figma.com/hc/en-us/articles/8085703771159-Manage-personal-access-tokens)。
