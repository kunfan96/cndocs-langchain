[Egnyte](https://www.egnyte.com) 是一个基于云的内容协作和文件共享平台，使组织能够安全地存储、共享和管理其文件。Egnyte 将云内容管理的强大功能与先进的安全性、合规性以及 AI 驱动的搜索能力相结合。

此包为 Egnyte 的混合搜索 API 提供了 LangChain 集成，该 API 结合了语义搜索和关键词搜索，帮助您从 Egnyte 实例中查找和检索文档。

## 安装与设置

<CodeGroup>
```bash pip
pip install -U egnyte-langchain-connector
```

```bash uv

```
</CodeGroup>

# egnyte-langchain-connector

此包包含与 Egnyte 的 LangChain 集成。有关 Egnyte 的更多信息，请查看 [Egnyte 开发者文档](https://developers.egnyte.com/)。

## 前提条件

要与 Egnyte 集成，您需要：

* 一个 Egnyte 帐户 — 如果您不是当前的 Egnyte 客户，或者想在生产环境 Egnyte 实例之外进行测试，您可以使用 [免费开发者帐户](https://developers.egnyte.com/member/register)。
* 一个 Egnyte 应用 — 这在 [开发者控制台](https://developers.egnyte.com/) 中配置，并且必须启用适当的权限范围。
* 该应用必须由管理员启用。

## 认证

`egnyte-langchain-connector` 包使用 Bearer 令牌与 Egnyte 用户令牌进行认证。

### 生成用户令牌

要生成用于认证的 Egnyte 用户令牌：

1. **注册开发者帐户**
   - 访问 [https://developers.egnyte.com/member/register](https://developers.egnyte.com/member/register)
   - 创建您的免费开发者帐户

2. **生成用户令牌**
   - 使用您的 API 密钥，按照 [公共 API 认证指南](https://developers.egnyte.com/docs/read/Public_API_Authentication) 生成用户令牌
   - **重要提示**：生成令牌时使用权限范围 `Egnyte.ai`，以确保正确访问 AI 驱动的搜索功能

### 使用令牌

您可以将令牌直接传递给检索器：

```python
import getpass

egnyte_user_token = getpass.getpass("Enter your Egnyte User Token: ")
domain = "company.egnyte.com"  # 您的 Egnyte 域名（不带 https://）
```

或者使用环境变量：

```python
import os
from dotenv import load_dotenv

load_dotenv()

egnyte_user_token = os.getenv("EGNYTE_USER_TOKEN")
domain = os.getenv("EGNYTE_DOMAIN")
```

## 实用工具

### EgnyteSearchOptions

配置高级搜索参数：

```python
from langchain_egnyte import EgnyteSearchOptions

search_options = EgnyteSearchOptions(
    limit=50,
    folderPath="/policies",
    excludeFolderPaths=["/temp", "/archive"],
    createdAfter=1640995200000,  # Unix 时间戳（毫秒）
    createdBefore=1672531200000
)
```
