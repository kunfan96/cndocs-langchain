>[DuckDuckGo搜索](https://github.com/deedy5/ddgs)是一个使用`DuckDuckGo.com`搜索引擎来搜索词语、文档、图片、视频、新闻、地图和文本翻译的包。它会将文件和图片下载到本地硬盘。

## 安装与设置

你需要安装一个Python包：

<CodeGroup>
```bash pip
pip install ddgs
```

```bash uv
uv add ddgs
```
</CodeGroup>

## 工具

查看一个[使用示例](/oss/python/integrations/tools/ddg)。

有两个可用的工具：

```python
from langchain_community.tools import DuckDuckGoSearchRun
from langchain_community.tools import DuckDuckGoSearchResults
```
