[OpenLM](https://github.com/r2d4/openlm) 是一个零依赖的、兼容 OpenAI 的 LLM 提供者，可以通过 HTTP 直接调用不同的推理端点。

它实现了 OpenAI Completion 类，因此可以作为 OpenAI API 的直接替代品。此变更集利用了 BaseOpenAI 以最小化额外代码。

本示例将介绍如何使用 LangChain 与 OpenAI 和 HuggingFace 进行交互。您需要从两者获取 API 密钥。

### 设置

安装依赖项并设置 API 密钥。

```python
# 如果尚未安装，请取消注释以安装 openlm 和 openai

pip install -qU  openlm
pip install -qU  langchain-openai
```

```python
import os
from getpass import getpass

# 检查是否设置了 OPENAI_API_KEY 环境变量
if "OPENAI_API_KEY" not in os.environ:
    print("请输入您的 OpenAI API 密钥:")
    os.environ["OPENAI_API_KEY"] = getpass()

# 检查是否设置了 HF_API_TOKEN 环境变量
if "HF_API_TOKEN" not in os.environ:
    print("请输入您的 HuggingFace Hub API 密钥:")
    os.environ["HF_API_TOKEN"] = getpass()
```

### 使用 LangChain 与 OpenLM

这里我们将在 LLMChain 中调用两个模型：来自 OpenAI 的 `text-davinci-003` 和 HuggingFace 上的 `gpt2`。

```python
from langchain_classic.chains import LLMChain
from langchain_community.llms import OpenLM
from langchain_core.prompts import PromptTemplate
```

```python
question = "法国的首都是什么？"
template = """问题: {question}

回答: 让我们一步一步思考。"""

prompt = PromptTemplate.from_template(template)

for model in ["text-davinci-003", "huggingface.co/gpt2"]:
    llm = OpenLM(model=model)
    llm_chain = LLMChain(prompt=prompt, llm=llm)
    result = llm_chain.run(question)
    print(
        """模型: {}
结果: {}""".format(model, result)
    )
```
