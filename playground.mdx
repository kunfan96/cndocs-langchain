## UI 框架集成

即插即用的 UI 组件库，旨在与 `@langchain/react` 开箱即用。

<CardGroup cols={1}>
<Card title="ai-elements" icon="package" href="https://ui-patterns.langchain.com/ai-elements/" cta="打开预览" target="_blank">
    用于构建 AI 聊天 UI 的无头、可组合 React 组件。底层使用 `useStream`，完全兼容 shadcn/ui。

    - 滚动粘性对话容器
