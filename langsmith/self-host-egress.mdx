<Info>
本页面仅适用于未在离线（气隙）模式下运行的客户，并假设您使用的是版本 0.9.0 或更高版本的自托管 LangSmith 实例。
</Info>

自托管 LangSmith 实例将所有信息存储在本地，永远不会将敏感信息发送到您的网络之外。但是，除非您在离线模式下运行，否则 LangSmith 需要出站连接到 `https://beacon.langchain.com` 以进行以下操作：

- **计费遥测** — 许可证验证和订阅/使用情况报告（必需）
- **运营遥测** — 用于支持诊断的日志、指标和跟踪（可选，可以禁用）
- **使用遥测** — 用于产品洞察的匿名使用情况快照（可选，可以禁用）

<Warning>
**必须出站连接到 `https://beacon.langchain.com`。** 如需静态 IP 地址，请参阅 [IP 地址白名单部分](/langsmith/cloud#allowlisting-ip-addresses)。
</Warning>

## 计费遥测

对于未在离线模式下运行的自托管 LangSmith 实例，计费遥测是**必需的**。这包括许可证验证和订阅/使用情况报告。

<Info>
计费遥测**无法禁用**。如果您需要在没有任何出站连接的情况下运行，请联系您的客户经理了解离线（气隙）许可证。
</Info>

### 功能说明

- **许可证验证**：在启动时及之后定期验证您的 LangSmith 许可证密钥。
- **订阅/使用情况报告**：根据您订单中的权限，报告用于计费目的的平台使用指标。

### 收集内容

- 许可证密钥验证请求
- 聚合的使用计数（跟踪数量、分配的席位数、使用的席位数）
- 组织和工作区标识符

### 示例有效负载

#### 许可证验证

**端点：** `POST beacon.langchain.com/v1/beacon/verify`

**请求：**

```json
{
  "license": "<YOUR_LICENSE_KEY>"
}
```

**响应：**

```json
{
  "token": "Valid JWT" //短期有效的 JWT 令牌，以避免重复的许可证检查
}
```

#### 订阅/使用情况报告

**端点：** `POST beacon.langchain.com/v1/beacon/ingest-traces`

**请求：**

## 运营遥测

从 **0.11** 版本开始，LangSmith 部署默认发送运营遥测。此遥测有助于 LangChain 团队为自托管实例提供主动支持和更快的故障排除。

<Info>
运营遥测与计费遥测**分开**。您可以在保持计费遥测活动的同时禁用运营遥测。
</Info>

### 功能说明

- 实现对自托管实例的主动支持和更快的故障排除
- 协助性能调优
- 根据实际使用模式帮助优先改进

### 收集内容

- **请求元数据**：匿名化的请求计数、大小和持续时间
- **数据库指标**：查询持续时间、错误率和性能计数器
- **运营跟踪**：高延迟或失败请求的计时和错误信息（这些**不是**客户跟踪——它们是关于 LangSmith 实例本身运行情况的跟踪）
- **日志消息**：仅警告和错误日志消息

<Info>
我们不收集实际的有效负载内容、数据库记录或任何可以识别您的最终用户或客户的数据。所有遥测数据都与组织和部署相关联，但永远不会与单个用户关联。我们**不收集任何形式的 PII**（个人身份信息）。
</Info>

### 如何禁用

您可以通过在 `langsmith_config.yaml` 文件中设置以下值来禁用运营遥测：

```yaml
config:
  telemetry:
    logs: false
    metrics: false
    traces: false
```

您也可以通过仅将特定值设置为 `false` 来禁用单个遥测类型。

<Warning>
禁用运营遥测会停止导出本节中描述的日志、指标和跟踪。它**不会**禁用计费遥测（许可证验证和订阅/使用情况报告）。
</Warning>

## 使用遥测

使用遥测收集您的 LangSmith 实例使用指标的匿名快照。这些数据有助于 LangChain 了解平台采用模式，并为产品开发决策提供信息。

<Info>
使用遥测**默认启用**，可以禁用。与计费遥测不同，您可以完全控制是否将这些快照发送给 LangChain。
</Info>

### 功能说明

- 定期捕获聚合的使用指标
- 提供对功能采用和平台增长的洞察
- 帮助 LangChain 根据实际使用情况优先改进和开发新功能

### 收集内容

- **平台指标**：工作区、项目、实验、数据集、评估器和其他平台资源的计数
- **功能使用情况**：运行规则、标注队列、提示和提示相关活动的计数
- **用户**：注册用户总数和过去 30 天内活动的 PAT（个人访问令牌）数量
- **时间戳**：快照的时间范围（UTC 中的起始/结束时间戳）

<Info>
所有指标**仅为聚合计数**。不收集单个资源数据、标识符或使用模式。我们不收集任何可能识别您的最终用户或客户的信息。
</Info>

### 如何禁用

您可以通过在部署配置中设置以下环境变量来禁用使用遥测：

```yaml
PHONE_HOME_USAGE_REPORTING_ENABLED: false
```

将其添加到 Helm 配置的 `commonEnv` 部分，以永久禁用使用遥测报告。

<Warning>
禁用使用遥测**不会**影响计费或运营遥测。许可证验证和订阅/使用情况报告将继续正常运行。
</Warning>

## 我们的承诺

LangChain 不会在计费或运营遥测中存储任何敏感信息。收集的任何数据都不会与第三方共享。日志消息经过过滤，仅包含错误严重级别，我们不会捕获可能包含敏感应用程序数据的日志消息。如果您对发送的数据有任何疑虑，请禁用遥测和/或联系您的客户经理。
