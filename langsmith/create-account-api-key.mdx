要开始使用 LangSmith，您需要创建一个账户。您可以在 [LangSmith UI](https://smith.langchain.com) 中注册一个免费账户。LangSmith 支持使用 Google、GitHub 和电子邮件登录。

## API 密钥

LangSmith 支持两种类型的 API 密钥。您可以使用这两种类型的令牌来向 LangSmith API 进行身份验证，但它们有不同的用例：

- [**个人访问令牌 (PATs)**](/langsmith/administration-overview#personal-access-tokens-pats) 继承创建它们的用户的权限。将 PATs 用于个人脚本或工具。
- [**服务密钥**](/langsmith/administration-overview#service-keys) 可以限定在特定的[工作区](/langsmith/administration-overview#workspaces)或整个[组织](/langsmith/administration-overview#organizations)范围内。将服务密钥用于应用程序和生产服务。

要使用 LangSmith 记录跟踪和运行评估，请创建一个 API 密钥来验证您的请求。

<Steps>
  <Step title="打开 API 密钥设置" icon="settings">
    导航到[设置页面](https://smith.langchain.com/settings)并选择 **API 密钥**部分。
  </Step>
  <Step title="配置密钥类型" icon="key">
    对于服务密钥，请在组织范围和工作区范围的密钥之间进行选择。如果密钥是工作区范围的，您必须指定工作区。

    [企业版](/langsmith/pricing-plans)用户还可以[为服务密钥分配特定的工作区角色](/langsmith/administration-overview#workspace-roles-rbac)，这可以独立于任何用户调整其权限。
  </Step>
  <Step title="设置过期时间" icon="calendar">
    设置密钥的过期时间。密钥在所选天数后将变得不可用，如果选择“永不过期”，则密钥不会过期。
  </Step>
  <Step title="创建密钥" icon="circle-check">
    点击 **创建 API 密钥。** LangSmith 将只显示一次 API 密钥，因此请确保将其复制并存储在安全的地方。
  </Step>
</Steps>

<Tip>
  要删除 API 密钥，请导航到[设置页面](https://smith.langchain.com/settings)，在 **API 密钥**部分找到该密钥，然后选择 **操作**列中的垃圾桶图标 <Icon icon="trash" iconType="solid"/>。
</Tip>

## 配置 SDK

安装适用于您语言的 SDK：

<Tabs>
  <Tab title="Python">
    <CodeGroup>
      ```bash pip
      pip install langsmith
      ```
      ```bash uv
      uv add langsmith
      ```
    </CodeGroup>
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install langsmith
    ```
  </Tab>
</Tabs>

有关完整详情，请参阅 [Python SDK](/langsmith/smith-python-sdk) 或 [JS/TS SDK](/langsmith/smith-js-ts-sdk) 参考文档。

然后，设置您的 API 密钥并启用跟踪：

```bash
export LANGSMITH_API_KEY=<your-api-key>
export LANGSMITH_TRACING=true
```

您可能还需要以下额外的环境变量。

`LANGSMITH_ENDPOINT` 控制 SDK 将数据发送到哪个 LangSmith 服务器。默认为 `https://api.smith.langchain.com`（美国云）。仅当您使用不同的部署时才设置它：

- 欧盟实例：`LANGSMITH_ENDPOINT=https://eu.api.smith.langchain.com`
- AWS 托管的美国实例：`LANGSMITH_ENDPOINT=https://aws.api.smith.langchain.com`

仅当您的 API 密钥限定在多个[工作区](/langsmith/administration-overview#workspaces)时，才需要 `LANGSMITH_WORKSPACE_ID`。在[设置页面](https://smith.langchain.com/settings)的 **常规**部分下找到您的工作区 ID：

`LANGSMITH_WORKSPACE_ID=<Workspace ID>`
