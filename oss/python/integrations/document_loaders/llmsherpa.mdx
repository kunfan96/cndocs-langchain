本笔记本介绍如何使用 `LLM Sherpa` 加载多种类型的文件。`LLM Sherpa` 支持不同的文件格式，包括 DOCX、PPTX、HTML、TXT 和 XML。

`LLMSherpaFileLoader` 使用 `LayoutPDFReader`，它是 LLMSherpa 库的一部分。该工具旨在解析 PDF 文件，同时保留其布局信息，而大多数 PDF 转文本解析器通常会丢失这些信息。

以下是 `LayoutPDFReader` 的一些关键特性：

*   它可以识别并提取章节和小节及其层级。
*   它可以将行合并成段落。
*   它可以识别章节和段落之间的链接。
*   它可以提取表格以及表格所在的章节。
*   它可以识别并提取列表和嵌套列表。
*   它可以连接跨页的内容。
*   它可以移除重复的页眉和页脚。
*   它可以移除水印。

请查阅 [llmsherpa](https://llmsherpa.readthedocs.io/en/latest/) 文档。

`注意：此库在某些 PDF 文件上会失败，因此请谨慎使用。`

## LLMSherpaFileLoader

在底层，`LLMSherpaFileLoader` 定义了一些策略来加载文件内容：["sections", "chunks", "html", "text"]，设置 [nlm-ingestor](https://github.com/nlmatics/nlm-ingestor) 以获取 `llmsherpa_api_url` 或使用默认值。

### sections 策略：返回解析为章节的文件

```python
from langchain_community.document_loaders.llmsherpa import LLMSherpaFileLoader

loader = LLMSherpaFileLoader(
    file_path="https://arxiv.org/pdf/2402.14207.pdf",
    new_indent_parser=True,
    apply_ocr=True,
    strategy="sections",
    llmsherpa_api_url="http://localhost:5010/api/parseDocument?renderFormat=all",
)
docs = loader.load()
```

### chunks 策略：返回解析为块的文件

```python
from langchain_community.document_loaders.llmsherpa import LLMSherpaFileLoader

loader = LLMSherpaFileLoader(
    file_path="https://arxiv.org/pdf/2402.14207.pdf",
    new_indent_parser=True,
    apply_ocr=True,
    strategy="chunks",
    llmsherpa_api_url="http://localhost:5010/api/parseDocument?renderFormat=all",
)
docs = loader.load()
```
