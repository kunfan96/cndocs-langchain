> [Infinispan](https://infinispan.org) Infinispan 是一个开源的内存数据网格，提供
> 键/值数据存储，能够容纳所有类型的数据，从 Java 对象到纯文本。
> 从版本 15 开始，Infinispan 支持对缓存进行向量搜索。

## 安装与设置
请参阅 [快速入门](https://infinispan.org/get-started/) 以运行 Infinispan 服务器，您可能需要禁用身份验证
（目前不支持）
