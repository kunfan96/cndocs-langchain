[Kinetica](https://www.kinetica.com/) 是一个专为在时序和空间数据上实现分析和生成式 AI 而构建的实时数据库。

## 聊天模型

Kinetica LLM 包装器使用 [Kinetica SqlAssist LLM](https://docs.kinetica.com/7.2/sql-gpt/concepts/) 将自然语言转换为 SQL，以简化数据检索过程。

用法请参阅 [Kinetica 语言转 SQL 聊天模型](/oss/python/integrations/chat/kinetica)。

```python
from langchain_kinetica import ChatKinetica
```

## 向量存储

Kinetica 向量存储包装器利用了 Kinetica 对[向量相似性搜索](https://docs.kinetica.com/7.2/vector_search/)的原生支持。

用法请参阅 [Kinetica 向量存储 API](/oss/python/integrations/vectorstores/kinetica)。

```python
from langchain_kinetica import KineticaVectorstore
```

## 文档加载器

Kinetica 文档加载器可用于从 [Kinetica](https://www.kinetica.com/) 数据库加载 LangChain [文档](https://reference.langchain.com/python/langchain-core/documents/base/Document)。

用法请参阅 [Kinetica 文档加载器](/oss/python/integrations/document_loaders/kinetica)。

```python
from langchain_kinetica import KineticaLoader
```

## 检索器

Kinetica 检索器可以根据非结构化查询返回文档。

用法请参阅 [基于 Kinetica 向量存储的检索器](/oss/python/integrations/retrievers/kinetica)。
