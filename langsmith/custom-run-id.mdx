---
title: 指定自定义运行 ID
description: 如何在使用 LangSmith 进行追踪时指定自定义运行 ID。
---

默认情况下，LangSmith 会为每个[运行](/langsmith/observability-concepts#runs)分配一个随机 ID。当您需要时，可以使用自定义 ID 覆盖此行为：

- 提前知道运行 ID（例如，在运行结束后立即附加[反馈](/langsmith/observability-concepts#feedback)）。
- 将 LangSmith 运行与外部系统的 ID 关联起来。
- 通过重用确定性 ID 使运行具有幂等性。

<Note>
我们建议使用 **UUID v7** 作为自定义运行 ID。UUIDv7 嵌入了时间戳，这可以确保追踪中运行的正确时间顺序。传递非 UUIDv7 的 ID 目前会发出警告，并且在未来版本中将成为必需。

[LangSmith SDK](/langsmith/reference) 导出了一个 `uuid7` 辅助函数（Python v0.4.43+，JS v0.3.80+）：

- **Python**: `from langsmith import uuid7`
- **JS/TS**: `import { uuid7 } from 'langsmith'`
</Note>

任何 UUID v7 字符串均可接受。您可以传递由 LangSmith SDK 辅助函数生成的 ID，或者如果您系统已使用 UUID v7 标识符，也可以传递您自己的 ID。

<Tabs>
  <Tab title="Python">
    ### 使用 `@traceable`

    在调用 [`@traceable`](https://reference.langchain.com/python/langsmith/run_helpers/traceable) 函数时，通过 `langsmith_extra` 传递 `run_id`：

    ```python Python
    from langsmith import traceable, uuid7

    @traceable
    def my_pipeline(question: str) -> str:
        return "answer"

    run_id = uuid7()
    my_pipeline("What is the capital of France?", langsmith_extra={"run_id": run_id})

    # run_id 现在可用于附加反馈、查询运行等。
    ```

    ### 使用 `trace` 上下文管理器

    直接将 `run_id` 传递给 [trace](https://reference.langchain.com/python/langsmith/run_helpers/trace) 上下文管理器构造函数，以设置该追踪块的 ID：

    ```python Python
    from langsmith import trace, uuid7

    run_id = uuid7()

    with trace("my-pipeline", run_id=run_id) as run:
        result = "answer"
        run.end(outputs={"result": result})

    # run_id 现在可用于附加反馈、查询运行等。
    ```
  </Tab>
  <Tab title="TypeScript">
    ### 使用 `traceable`

    在传递给 [`traceable`](https://reference.langchain.com/javascript/langsmith/traceable/traceable) 的配置对象中传递 `id`：

    ```typescript TypeScript
    import { traceable } from "langsmith/traceable";
    import { uuid7 } from "langsmith";

    const runId = uuid7();

    const myPipeline = traceable(
      async (question: string) => {
        return "answer";
      },
      { name: "my-pipeline", id: runId }
    );

    await myPipeline("What is the capital of France?");

    // runId 现在可用于附加反馈、查询运行等。
    ```

  </Tab>
</Tabs>
