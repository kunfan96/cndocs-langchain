---
title: MULTIPLE_SUBGRAPHS
---

当您[在节点内调用子图](/oss/javascript/langgraph/use-subgraphs#call-a-subgraph-inside-a-node)多次，且该子图使用 `checkpointer=True`（延续模式）编译时，会发生此错误。

## 故障排除

根据您的需求选择以下方案之一：

1. **不需要中断？** 使用 `checkpointer: false` 完全禁用检查点：
   ```typescript
   const subgraph = subgraphBuilder.compile({ checkpointer: false });
   ```

2. **需要中断但不需要跨调用持久化？** 使用默认的继承模式，省略 `checkpointer`：
   ```typescript
   const subgraph = subgraphBuilder.compile();
   ```
   每次调用都会获得唯一的命名空间，因此可以并行执行。子图每次都会重新开始，但可以使用 `interrupt()`。

3. **需要跨调用持久化？** 使用 `checkpointer: true`。LangGraph 会为每次调用分配一个基于位置的命名空间后缀（`calling_node`、`calling_node|1` 等）以防止冲突。若要使用稳定的、基于名称的命名空间，请为每个子图包装一个唯一的节点名称——参见[并行子图](/oss/javascript/langgraph/use-subgraphs#subgraph-persistence)。
