Dell 是一家全球性的技术公司，提供一系列硬件、软件和服务，包括人工智能解决方案。其人工智能产品组合包括专为人工智能工作负载构建的基础设施，例如针对人工智能数据管理优化的 Dell PowerScale 存储系统。

## PowerScale

Dell [PowerScale](https://www.dell.com/en-us/shop/powerscale-family/sf/powerscale) 是一个企业级横向扩展存储系统，托管业界领先的 OneFS 文件系统，可部署在本地或云端。

### 安装与设置

<CodeGroup>
```bash pip
pip install powerscale-rag-connector
```

```bash uv
uv add powerscale-rag-connector
```
</CodeGroup>
