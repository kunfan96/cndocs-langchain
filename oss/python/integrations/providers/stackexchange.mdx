>[Stack Exchange](https://en.wikipedia.org/wiki/Stack_Exchange) 是一个由
涵盖不同领域主题的问答（Q&A）网站组成的网络，每个网站覆盖一个特定主题，其中的问题、答案和用户都遵循一个声誉奖励流程。

本页介绍如何在 LangChain 中使用 `Stack Exchange API`。

## 安装与设置
- 使用以下命令安装依赖项：
<CodeGroup>
```bash pip
pip install stackapi
```

```bash uv
uv add stackapi
```
</CodeGroup>

## 包装器

### 实用工具

存在一个 StackExchangeAPIWrapper 实用工具，它封装了此 API。要导入此实用工具：

```python
from langchain_community.utilities import StackExchangeAPIWrapper
```

有关此包装器的更详细演练，请参阅[此笔记本](/oss/python/integrations/tools/stackexchange)。

### 工具

您也可以轻松地将此包装器作为工具加载（用于与代理配合使用）。
您可以通过以下方式实现：
```python
from langchain_community.agent_toolkits.load_tools import load_tools
tools = load_tools(["stackexchange"])
```

有关工具的更多信息，请参阅[工具](/oss/python/integrations/tools)。
