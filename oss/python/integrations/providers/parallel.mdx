本页涵盖了所有 LangChain 与 [Parallel](https://platform.parallel.ai/) 的集成。

## 安装与设置

`Parallel` 集成位于其独立的[合作伙伴包](https://pypi.org/project/langchain-parallel/)中：

<CodeGroup>
    ```bash pip
    pip install -U langchain-parallel
    ```
    ```bash uv
    uv add langchain-parallel
    ```
</CodeGroup>

将 `PARALLEL_API_KEY` 环境变量设置为您的 Parallel API 密钥。请在 [platform.parallel.ai](https://platform.parallel.ai) 注册以获取密钥。
