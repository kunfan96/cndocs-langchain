本节介绍如何托管和管理 LangSmith 基础设施。您可以为[可观测性](/langsmith/observability)、[评估](/langsmith/evaluation)和[提示工程](/langsmith/prompt-engineering)设置 LangSmith，或者使用完整的平台体验，通过 [LangSmith 部署](/langsmith/deployment)来部署和管理您的应用程序。

<Callout icon="building" color="#2563EB" iconType="regular">
**如果您正在设置或维护 LangSmith 基础设施，请从此处开始。**

如果您想部署代理应用程序，[代理部署部分](/langsmith/deployment)涵盖了应用程序结构和部署配置。
</Callout>

## 选择如何设置 LangSmith

您可以以以下三种模式之一部署 LangSmith：
- [**云**](/langsmith/cloud)：完全由 LangChain 托管
- [**混合**](/langsmith/hybrid)：LangChain 管理<Tooltip tip="用于管理部署的 LangSmith UI 和 API。">控制平面</Tooltip>；您托管<Tooltip tip="您的代理服务器和代理执行的运行时环境。">数据平面</Tooltip>
- [**自托管**](/langsmith/self-hosted)：您在自己的基础设施内管理整个技术栈

<Callout>
混合和自托管部署选项在企业版计划中可用。[获取演示](https://www.langchain.com/contact-sales)以了解更多信息。
</Callout>

### 比较

请参考下表进行比较：

| 功能 | **云** | **混合** | **自托管** |
|---------|-----------|------------|-----------------|
| **基础设施位置** | LangChain 的云 | 分离：控制平面在 LangChain 云中，数据平面在您的云中 | 您的云 |
| **谁管理更新** | LangChain | LangChain（控制平面），您（数据平面） | 您 |
| **谁管理您应用的 CI/CD** | LangChain | 您 | 您 |
| **可以部署应用程序吗？** | ✅ 是 | ✅ 是 | ✅ 是（需启用 LangSmith 部署） |
| **可观测性数据位置** | LangChain 云 | LangChain 云 | 您的云 |
| **[定价](https://www.langchain.com/pricing)** | Plus 层级 | 企业版 | 企业版 |
| **最适合** | 快速设置，托管基础设施 | 数据驻留要求 + 托管控制平面 | 完全控制，数据隔离 |

<Tip>
您可以[在本地免费运行代理服务器](/langsmith/local-dev-testing)进行测试和开发。
</Tip>
