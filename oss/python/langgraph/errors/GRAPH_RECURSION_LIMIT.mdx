---
title: GRAPH_RECURSION_LIMIT
---

您的 LangGraph [`StateGraph`](https://langchain-ai.github.io/langgraph/reference/graphs/#langgraph.graph.state.StateGraph) 在达到停止条件之前，已达到最大步数限制。
这通常是由类似以下示例的代码导致的无限循环引起的：

```python
class State(TypedDict):
    some_key: str

builder = StateGraph(State)
builder.add_node("a", ...)
builder.add_node("b", ...)
builder.add_edge("a", "b")
builder.add_edge("b", "a")
...

graph = builder.compile()
```

然而，复杂的图可能会自然地达到默认限制。

## 故障排除

* 如果您不期望您的图经历多次迭代，那么您可能遇到了循环。请检查您的逻辑是否存在无限循环。

* 如果您有一个复杂的图，可以在调用图时向 `config` 对象传入更高的 `recursion_limit` 值，如下所示：

```python
graph.invoke({...}, {"recursion_limit": 100})
```
