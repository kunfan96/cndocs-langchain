>[CoNLL-U](https://universaldependencies.org/format.html) 是 CoNLL-X 格式的修订版。注释以纯文本文件（UTF-8，规范化为 NFC，仅使用 LF 字符作为换行符，文件末尾包含一个 LF 字符）编码，包含三种类型的行：
>
>- 包含单词/词元注释的词行，注释位于由单个制表符分隔的 10 个字段中；见下文。
>- 标记句子边界的空行。
>- 以井号 (#) 开头的注释行。

这是一个如何加载 [CoNLL-U](https://universaldependencies.org/format.html) 格式文件的示例。整个文件被视为一个文档。示例数据 (`conllu.conllu`) 基于标准 UD/CoNLL-U 示例之一。

```python
from langchain_community.document_loaders import CoNLLULoader
```

```python
loader = CoNLLULoader("example_data/conllu.conllu")
```

```python
document = loader.load()
```

```python
document
```

```python
[Document(page_content='They buy and sell books.', metadata={'source': 'example_data/conllu.conllu'})]
```
