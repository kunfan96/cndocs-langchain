>[PubMed®](https://pubmed.ncbi.nlm.nih.gov/) 由 `美国国家生物技术信息中心、国家医学图书馆` 维护，包含超过 3500 万条来自 `MEDLINE`、生命科学期刊和在线书籍的生物医学文献引文。引文可能包含指向 `PubMed Central` 和出版商网站全文内容的链接。

本笔记本介绍如何使用 `PubMed` 作为检索器。

```python
from langchain_community.retrievers import PubMedRetriever
```

```python
retriever = PubMedRetriever()
```

```python
retriever.invoke("chatgpt")
```
