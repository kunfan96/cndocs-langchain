## 概述

本指南演示如何使用[深度代理](/oss/javascript/deepagents)构建一个数据分析代理。数据分析任务通常需要规划、代码执行以及处理脚本、报告和图表等制品——这些正是深度代理旨在处理的能力。

我们将构建的代理将：

1. 接受一个 CSV 文件进行分析
2. 执行探索性数据分析并生成可视化
3. 将结果共享到 Slack 频道

<Tip>
Slack 集成是可选的。可以修改代理以将制品保存在本地或通过其他渠道共享结果。
</Tip>

### 关键概念

本教程涵盖：

- 用于沙箱化代码执行的[后端](/oss/javascript/deepagents/backends)
- 用于外部集成的自定义[工具](/oss/javascript/langchain/tools)

## 实现自定义工具

数据分析任务可能会产生制品，如报告或图表。
以下简单的[工具](/oss/javascript/langchain/tools)使用 `backend.download_files` 下载它们，然后使用 Slack SDK 上传。
我们也可以要求代理列出相关文件路径而不是上传它们，以便相关方可以根据需要单独获取。

```python
from langchain.tools import tool
from slack_sdk import WebClient


slack_token = os.environ["SLACK_USER_TOKEN"]
slack_client = WebClient(token=slack_token)


@tool(parse_docstring=True)
def slack_send_message(text: str, file_path: str | None = None) -> str:
    """发送消息，可选择包含图像等附件。

    Args:
        text: (str) 消息的文本内容
        file_path: (str) 文件系统中附件的文件路径。
    """
    if not file_path:
        slack_client.chat_postMessage(channel=channel, text=text)
    else:
        fp = backend.download_files([file_path])
        slack_client.files_upload_v2(
            channel="C0123456ABC",  # 在此处指定您自己的频道
            content=fp[0].content,
            initial_comment=text,
        )

    return "消息已发送。"
```
<Note>
通常，最好避免将凭证和其他机密信息添加到沙箱中。这里我们在沙箱外的工具中管理 Slack 令牌。
</Note>

## 运行代理

让我们实例化一个代理：

```python
from langchain_core.utils.uuid import uuid7

from langgraph.checkpoint.memory import InMemorySaver
from deepagents import create_deep_agent


checkpointer = InMemorySaver()

agent = create_deep_agent(
    model="google_genai:gemini-3.1-pro-preview",
    tools=[slack_send_message],
    backend=backend,
    checkpointer=checkpointer,
)

thread_id = str(uuid7())
config={"configurable": {"thread_id": thread_id}}
```

我们包括：
- [模型](/oss/javascript/deepagents/customization#model)的选择
- 我们的自定义[工具](/oss/javascript/deepagents/customization#tools)
- [后端](/oss/javascript/deepagents/backends)
- 用于支持多轮对话的[检查点](/oss/javascript/langchain/short-term-memory)

现在让我们调用我们的代理。
```python
input_message = {

    ),
}
for step in agent.stream(
    {"messages": [input_message]},
    config,
    stream_mode="updates",
):
    for _, update in step.items():
        if update and (messages := update.get("messages")) and isinstance(messages, list):
            for message in messages:
                message.pretty_print()
```
