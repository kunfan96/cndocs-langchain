本笔记本介绍如何使用 LangChain 与 [YandexGPT](https://cloud.yandex.com/en/services/yandexgpt) 嵌入模型。

要使用，您应该已安装 `yandexcloud` Python 包。

```python
pip install -qU  yandexcloud
```

首先，您应该[创建一个具有 `ai.languageModels.user` 角色的服务账户](https://cloud.yandex.com/en/docs/iam/operations/sa/create)。

接下来，您有两个身份验证选项：

- [IAM 令牌](https://cloud.yandex.com/en/docs/iam/operations/iam-token/create-for-sa)。
    您可以在构造函数参数 `iam_token` 或环境变量 `YC_IAM_TOKEN` 中指定令牌。
- [API 密钥](https://cloud.yandex.com/en/docs/iam/operations/api-key/create)。
    您可以在构造函数参数 `api_key` 或环境变量 `YC_API_KEY` 中指定密钥。

要指定模型，您可以使用 `model_uri` 参数，更多详情请参阅[文档](https://cloud.yandex.com/en/docs/yandexgpt/concepts/models#yandexgpt-embeddings)。

默认情况下，使用参数 `folder_id` 或环境变量 `YC_FOLDER_ID` 指定文件夹中的最新版本 `text-search-query`。

```python
from langchain_community.embeddings.yandex import YandexGPTEmbeddings
```

```python
embeddings = YandexGPTEmbeddings()
```

```python
text = "This is a test document."
```

```python
query_result = embeddings.embed_query(text)
```

```python
doc_result = embeddings.embed_documents([text])
```

```python
query_result[:5]
```

