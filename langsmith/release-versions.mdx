自托管 LangSmith 通过两个发布渠道发布：一个供客户在生产环境中运行的稳定渠道，以及一个跟踪下一个主要版本的预览渠道。

## 发布渠道

### 稳定

当前正式发布的主要版本。这是我们推荐用于生产的渠道。稳定渠道仅接收包含关键错误修复和安全补丁的每周补丁版本。在主要版本之间，稳定渠道不会发布任何新功能、数据迁移或基础设施变更。

在任何给定时间，最新的主要版本 (N) 是预览渠道，而上一个主要版本 (N-1) 是稳定渠道。

### 预览

下一个主要版本的开发构建。预览版包含随着它们合并到 LangSmith SaaS 中的新功能和修复，让您提前了解下一个主要版本将包含的内容。预览版构建可能包含数据迁移，但绝不会添加或移除服务或引入破坏性变更。

预览版旨在用于测试和预发布环境的评估。我们不建议在生产环境中运行预览版。

## 发布节奏

| 渠道 | 节奏 |
|---------|---------|
| 预览 | 发布节奏与 LangSmith SaaS 发布节奏同步 |
| 稳定 — 新主要版本 (`v0.X.0`) | 大约每 6 周一次（每季度两次） |
| 稳定 — 补丁 (`v0.X.Y`) | 每周一次（通常是周五），如果没有变更则跳过。针对关键客户问题会发布临时版本。 |

## 各渠道发布内容

|  | 预览 | 稳定补丁 | 下一个主要版本 |
|--|:-:|:-:|:-:|
| 新功能 | 是 | 否 | 是 |
| 错误修复 | 是 | 仅关键修复 | 是 |
| 安全补丁 | 是 | 是 | 是 |
| 数据迁移和回填 | 是 | 否 | 是 |
| 新增或移除的服务 | 否 | 否 | 是 |
| 破坏性变更 | 否 | 否 | 是 |

服务的添加、移除和破坏性变更仅出现在新的主要版本中，因此在计划升级到新主要版本时请考虑这一点。

## 版本编号

自托管 LangSmith 使用以下方案：

- `v0.X.0` — 主要版本（稳定正式发布版本）
- `v0.X.Y` — 稳定补丁版本（仅包含关键修复）
- `v0.X.0-rcN` — 下一个主要版本的预览构建（候选发布版本），其中 `N` 是递增的构建编号

## 建议

- **在生产环境中运行稳定版。** 预览版仅用于评估，可能包含尚未验证的未发布功能。
- **在测试或预发布环境中使用预览版。** 在非生产环境中运行预览版是尽早发现问题并为下一次主要升级做准备的最佳方式。
- **规划主要版本升级。** 数据迁移、服务添加或移除以及破坏性变更仅出现在新的主要版本中。升级前请查阅[自托管更新日志](/langsmith/self-hosted-changelog)，并规划任何所需的数据或基础设施变更。
- **保持在受支持的版本上。** 我们建议在每个新主要版本发布后尽快升级，以按照我们推荐的节奏获取架构改进。

## 当前版本

要检查当前的稳定版和预览版版本，请参阅[自托管更新日志](/langsmith/self-hosted-changelog)。
