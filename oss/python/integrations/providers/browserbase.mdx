[Browserbase](https://browserbase.com) 是一个开发者平台，用于可靠地运行、管理和监控无头浏览器。

通过以下方式为您的 AI 数据检索提供支持：
- [无服务器基础设施](https://docs.browserbase.com/under-the-hood)，提供可靠的浏览器以从复杂 UI 中提取数据
- [隐身模式](https://docs.browserbase.com/features/stealth-mode)，包含指纹识别策略和自动验证码解决
- [会话调试器](https://docs.browserbase.com/features/sessions)，用于检查您的浏览器会话，包含网络时间线和日志
- [实时调试](https://docs.browserbase.com/guides/session-debug-connection/browser-remote-control)，用于快速调试您的自动化流程

## 安装与设置

- 从 [browserbase.com](https://browserbase.com) 获取 API 密钥和项目 ID，并将其设置在环境变量中（`BROWSERBASE_API_KEY`、`BROWSERBASE_PROJECT_ID`）。
- 安装 [Browserbase SDK](https://github.com/browserbase/python-sdk)：

```bash
pip install browserbase
```

## 文档加载器

查看[使用示例](/oss/python/integrations/document_loaders/browserbase)。

## Deep Agents 集成

[Deep Agents](/oss/python/deepagents/overview) 与 Browserbase 配合良好，它将浏览器功能作为 Python 工具暴露出来，而不是通过 CLI 路由。这种集成模式为主规划器提供了廉价、无状态的搜索和页面检索工具，同时将昂贵的渲染和交互式浏览器工作委托给专用的 `browser-specialist` 子代理。

### 安装

```bash
pip install deepagents browserbase stagehand langchain-openai python-dotenv
```

### 架构

推荐的模式使用四个工具：

| 工具 | 描述 | 何时使用 |
|------|------|----------|
| `browserbase_search` | 通过 Browserbase Search API 进行网络搜索 | 发现阶段——始终首先尝试此工具 |
| `browserbase_fetch` | 通过 Browserbase Fetch API 进行无头页面检索 | 静态页面、快速阅读、无需 JS |
| `browserbase_rendered_extract` | 通过 Stagehand 进行完整浏览器会话 | JS 密集型或已渲染页面（只读） |
| `browserbase_interactive_task` | 用于多步骤浏览器任务的 Stagehand 代理 | 点击、表单填写、登录流程 |

廉价工具（`search`、`fetch`）位于主规划器上。昂贵的浏览器工具位于 `browser-specialist` 子代理上，将嘈杂的会话输出与主线程隔离。

### 环境变量

```bash
export BROWSERBASE_API_KEY="bb_..."

# 可选：模型覆盖
export DEEPAGENT_MODEL="gpt-5.4"
export DEEPAGENT_BASE_URL="https://<your-openai-compatible-gateway>"
export STAGEHAND_MODEL="google/gemini-3-flash-preview"
export STAGEHAND_AGENT_MODEL="anthropic/claude-sonnet-4-6"
```

### 定义工具

```python
import asyncio
import os
from browserbase import Browserbase
from bs4 import BeautifulSoup
from langchain.tools import tool
from stagehand import AsyncStagehand

@tool
def browserbase_search(query: str, num_results: int = 5) -> str:
    """使用 Browserbase 搜索网络。在打开页面之前，首先使用此工具进行发现。"""
    bb = Browserbase(api_key=os.environ["BROWSERBASE_API_KEY"])
    response = bb.search.web(query=query, num_results=max(1, min(num_results, 10)))
    results = [
        {"title": r.title, "url": r.url}
        for r in getattr(response, "results", [])
    ]
    return str({"query": query, "results": results})


@tool
def browserbase_fetch(url: str, use_proxy: bool = False, max_chars: int = 12000) -> str:
    """无需浏览器会话即可获取页面内容。最适合静态页面和快速阅读。"""
    bb = Browserbase(api_key=os.environ["BROWSERBASE_API_KEY"])
    response = bb.fetch_api.create(url=url, proxies=use_proxy)
    content = str(getattr(response, "content", ""))
    soup = BeautifulSoup(content, "html.parser")
    for tag in soup(["script", "style"]):
        tag.decompose()
    text = (soup.body or soup).get_text("\n", strip=True)[:max_chars]
    return str({"url": url, "status_code": response.status_code, "text": text})


@tool
def browserbase_rendered_extract(start_url: str, instruction: str) -> str:
    """打开一个完整的 Browserbase 浏览器会话，并使用 Stagehand 提取已渲染的内容。"""
    return asyncio.run(_rendered_extract(start_url, instruction))


@tool
def browserbase_interactive_task(start_url: str, task: str) -> str:
    """打开一个 Browserbase 托管的 Stagehand 会话，并执行多步骤浏览器任务。"""
    return asyncio.run(_interactive_task(start_url, task))


async def _rendered_extract(start_url: str, instruction: str) -> str:
    client = AsyncStagehand(browserbase_api_key=os.environ["BROWSERBASE_API_KEY"])
    resp = await client.sessions.start(model_name=os.getenv("STAGEHAND_MODEL", "google/gemini-3-flash-preview"))
    session_id = resp.data.session_id
    try:
        await client.sessions.navigate(id=session_id, url=start_url, frame_id="")
        result = await client.sessions.extract(id=session_id, instruction=instruction)
        return str({"session_id": session_id, "result": getattr(getattr(result, "data", None), "result", None)})
    finally:
        await client.sessions.end(id=session_id)


async def _interactive_task(start_url: str, task: str) -> str:
    model = os.getenv("STAGEHAND_AGENT_MODEL", "anthropic/claude-sonnet-4-6")
    client = AsyncStagehand(browserbase_api_key=os.environ["BROWSERBASE_API_KEY"])
    resp = await client.sessions.start(model_name=model)
    session_id = resp.data.session_id
    try:
        await client.sessions.navigate(id=session_id, url=start_url, frame_id="")
        result = await client.sessions.execute(
            id=session_id,
            execute_options={"instruction": task, "max_steps": 20},
            agent_config={"model": model, "instructions": "精确执行浏览器任务，完成后停止。"},
            timeout=300.0,
        )
        return str(result)
    finally:
        await client.sessions.end(id=session_id)
```

### 构建代理

```python
import uuid
from deepagents import create_deep_agent
from langgraph.checkpoint.memory import MemorySaver
from langchain_openai import ChatOpenAI

BROWSER_SUBAGENT = {
    "name": "browser-specialist",
    "description": "通过 Browserbase 处理 JS 密集型浏览、已渲染内容提取和交互式浏览器任务。",
    "system_prompt": (
        "你是一个 Browserbase 浏览专家。"
        "使用 browserbase_rendered_extract 对已渲染页面进行只读工作。"
        "仅在需要有状态操作（如点击、输入或提交表单）时使用 browserbase_interactive_task。"
        "返回包含相关页面 URL 和任务是否成功的简洁摘要。"
    ),
    "tools": [browserbase_rendered_extract, browserbase_interactive_task],
}

agent = create_deep_agent(
    model=ChatOpenAI(model="gpt-5.4", api_key=os.environ["OPENAI_API_KEY"]),
    tools=[browserbase_search, browserbase_fetch],
    subagents=[BROWSER_SUBAGENT],
    system_prompt=(
        "你是一个使用 Browserbase 工具的研究型 Deep Agent。"
        "首先使用 browserbase_search 进行发现。"
        "优先使用 browserbase_fetch 快速阅读静态页面。"
        "将 JS 密集型或交互式工作委托给 browser-specialist 子代理。"
    ),
    # 将交互式浏览器操作置于人工批准之后
    interrupt_on={
        "browserbase_interactive_task": {
            "allowed_decisions": ["approve", "edit", "reject"]
        }
    },
    checkpointer=MemorySaver(),
)
```

### 使用人在回路中批准运行

`interrupt_on` 会在任何 `browserbase_interactive_task` 调用之前暂停执行，以便您可以在代理提交操作之前审查提议的操作。

```python
from langgraph.types import Command

config = {"configurable": {"thread_id": str(uuid.uuid4())}}
result = agent.invoke(
    {"messages": [{"role": "user", "content": "研究 Browserbase Fetch API 并解释何时应升级到完整浏览器会话。"}]},
    config=config,
    version="v2",
)

# 在每次中断后恢复（批准 / 编辑 / 拒绝）
while result.interrupts:
    interrupt_value = result.interrupts[0].value
    for action in interrupt_value["action_requests"]:
        print(f"待处理: {action['name']}\n参数: {action['args']}")
    decision = input("决定 [approve/edit/reject]: ").strip().lower()
    result = agent.invoke(
        Command(resume={"decisions": [{"type": decision}]}),
        config=config,
        version="v2",
    )
```

### 决策树：使用哪个工具

```
用户查询
  └─ 是否已知特定 URL？
       ├─ 否 → browserbase_search（首先发现 URL）
       └─ 是 ↓
            页面是否由 JavaScript 渲染？
              ├─ 否 → browserbase_fetch（快速、无状态）
              └─ 是 ↓
                   任务是否需要交互（点击 / 登录 / 表单）？
                     ├─ 否 → browserbase_rendered_extract（只读完整浏览器）
                     └─ 是 → browserbase_interactive_task（Stagehand 代理，触发 interrupt_on）
```
