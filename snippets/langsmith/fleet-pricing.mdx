## 什么是 Fleet 运行？

LangSmith Fleet 运行是对 Fleet 代理的完整调用，由接收消息或事件触发，无论是自动触发还是手动发送。Fleet 运行包括通过已配置触发器（包括第三方集成或其他连接服务）传递给代理的所有消息，以及通过 Fleet 用户界面（例如通过聊天界面）直接发送的消息。如果调用成功或被中断，则计为一次 Fleet 运行。在人在环路中断后恢复执行构成一次单独的 Fleet 运行。执行失败不计为 Fleet 运行。

## Fleet 定价是否包含模型费用？

不包含。模型使用费用由您的模型提供商单独计费。Fleet 允许您选择所需的模型（例如 Anthropic、OpenAI、Gemini 或其他提供商），并使用您的提供商 API 密钥进行连接。有关配置模型的更多信息，请参阅[工作区管理员](/langsmith/fleet/workspace-admin)页面。

## Fleet 定价是否包含代理工具？

Fleet 包含内置工具，并支持通过远程 MCP 服务器连接第三方工具。第三方工具通常需要您使用自己的账户进行身份验证，任何费用或使用费由第三方提供商收取。有关设置工具密钥的更多信息，请参阅[工作区管理员](/langsmith/fleet/workspace-admin)页面。

## Fleet 运行是否在 LangSmith 中自动追踪，是否计入账单？

是的。每次 Fleet 运行都会在 LangSmith 中自动追踪。这些追踪归属于用户账户，并计入客户 LangSmith 计划下的基于使用量的账单。

## 如何禁用 Fleet？

如果您使用的是自托管 LangSmith 实例，可以通过在 `values.yaml` 中将以下设置为 `false` 来禁用 Fleet：

```yaml
backend:
  agentBootstrap:
    enabled: false

config:
  agentBuilder:
    enabled: false

agentBuilderToolServer:
  enabled: false

agentBuilderTriggerServer:
  enabled: false
```

如果您使用的是云端 LangSmith，请[联系我们的支持团队](https://support.langchain.com/)以禁用 Fleet。
