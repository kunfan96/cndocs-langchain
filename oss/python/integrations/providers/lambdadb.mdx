title: LambdaDB
---

>[LambdaDB](https://lambdadb.ai/) 是一个用于 RAG 和智能体的无服务器 AI 数据库。它在一个灵活的文档模型上统一了全文搜索、多向量搜索和混合搜索。能够即时处理无限持久化记忆和海量并发——成本仅为 1/10。

## 安装与设置

安装 Python SDK：

<CodeGroup>
    ```bash pip
    pip install langchain-lambdadb
    ```

    ```bash uv
    uv add langchain-lambdadb
    ```
</CodeGroup>

您还需要一个 LambdaDB 账户，其中包含：
- 项目 URL
- 项目 API 密钥

在 [lambdadb.ai](https://lambdadb.ai) 获取您的凭证。

## 向量存储

存在一个围绕 `LambdaDB` 集合的封装器，允许您将其用作向量存储，用于语义搜索、RAG 和其他 AI 应用程序。

要导入此向量存储：
```python
from langchain_lambdadb import LambdaDBVectorStore
```

### 快速开始

```python
from langchain_lambdadb import LambdaDBVectorStore
from langchain_openai import OpenAIEmbeddings
from lambdadb import LambdaDB
import os

# 初始化客户端
client = LambdaDB(
    server_url=os.environ["LAMBDADB_SERVER_URL"],
    project_api_key=os.environ["LAMBDADB_API_KEY"]
)

# 使用现有集合创建向量存储
vector_store = LambdaDBVectorStore(
    client=client,
    collection_name="my_collection",  # 必须事先存在
    embedding=OpenAIEmbeddings()
)
```

有关 LambdaDB 封装器的更详细演练，请参阅[完整文档](/oss/python/integrations/vectorstores/lambdadb)。
