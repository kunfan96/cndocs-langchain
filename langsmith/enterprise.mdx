## 部署选项

选择如何托管 LangSmith 以匹配您的基础设施和数据驻留要求。

<CardGroup cols={3}>
  <Card title="云托管" icon="cloud" href="/langsmith/cloud">
    在 LangSmith 的托管云中托管 LangSmith，支持美国或欧盟数据驻留。
  </Card>
  <Card title="混合部署" icon="topology-complex" href="/langsmith/hybrid">
    在 LangSmith 的云中运行控制平面，在您自己的 VPC 中运行数据平面，实现完全的数据隔离。
  </Card>
  <Card title="自托管" icon="server-2" href="/langsmith/self-hosted">
    使用 Docker Compose 或 Kubernetes 将 LangSmith 完全部署在您自己的基础设施内。
  </Card>
</CardGroup>

## 访问控制

控制组织内谁可以访问什么。

<CardGroup cols={2}>
  <Card title="基于角色的访问控制 (RBAC)" icon="shield-lock" href="/langsmith/rbac">
    使用内置或自定义角色为每个工作区定义权限。仅在企业计划中提供。
  </Card>
  <Card title="基于属性的访问控制 (ABAC)" icon="tag" href="/langsmith/abac">
    应用细粒度的、基于标签的访问策略来限制资源访问——包括阻止特定用户访问个人身份信息数据。
  </Card>
  <Card title="工作负载隔离" icon="layout-sidebar" href="/langsmith/workload-isolation">
    使用多工作区模型来隔离团队、建立信任边界并分离环境。
  </Card>
  <Card title="资源标签" icon="tag" href="/langsmith/set-up-resource-tags">
    为资源添加标签，以用于 ABAC 策略并组织开发、预生产和生产等环境。
  </Card>
</CardGroup>
