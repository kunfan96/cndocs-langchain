本笔记本介绍如何使用 [`SitemapLoader`](https://reference.langchain.com/javascript/langchain-community/document_loaders/web/sitemap/SitemapLoader) 类将站点地图加载为 `Document` 对象。

## 设置

首先，我们需要安装 `langchain` 包：

```bash npm
npm install @langchain/core @langchain/community
```

传入的 URL 必须包含指向站点地图的 `.xml` 路径，否则默认的 `/sitemap.xml` 将被附加到 URL 后。

```typescript
import { SitemapLoader } from "@langchain/community/document_loaders/web/sitemap";

const loader = new SitemapLoader("https://www.langchain.com/");

const docs = await loader.load();
console.log(docs.length);
/**
26
```

或者，如果您只想加载站点地图本身，而不加载站点地图中每个页面的内容，可以使用 `parseSitemap` 方法：

```typescript
import { SitemapLoader } from "@langchain/community/document_loaders/web/sitemap";

const loader = new SitemapLoader("https://www.langchain.com/");

const sitemap = await loader.parseSitemap();
console.log(sitemap);
```
