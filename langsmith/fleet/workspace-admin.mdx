配置工作区密钥并管理 Fleet 代理和用户的支出限额。

## 工作区密钥

Fleet 使用[工作区密钥](/langsmith/set-up-hierarchy#configure-workspace-settings)来存储模型和工具的 API 密钥。以下是可用的密钥类型：

- **必需的模型密钥**：Fleet 需要 OpenAI 或 Anthropic API 密钥才能进行 LLM API 调用。代理图从工作区密钥中加载此密钥用于推理。
- **Fleet 特定密钥**：以 `FLEET_` 为前缀的密钥在 Fleet 内部优先于工作区密钥。这样，您可以更好地跟踪 Fleet 与 LangSmith 中使用相同密钥的其他部分的使用情况。如果您同时拥有 `OPENAI_API_KEY` 和 `FLEET_OPENAI_API_KEY`，则将使用 `FLEET_OPENAI_API_KEY` 密钥。
- **可选的工具密钥**：为您启用的任何工具添加密钥。这些密钥在运行时从工作区密钥中读取。
  - `EXA_API_KEY`：Exa 搜索工具（通用网络和 LinkedIn 个人资料搜索）所需。
  - `TAVILY_API_KEY`：Tavily 网络搜索所需。
  - `TWITTER_API_KEY` 和 `TWITTER_API_KEY_SECRET`：Twitter/X 读取操作（仅应用承载令牌）所需。未启用发布/媒体上传功能。
- **MCP 服务器配置**：Fleet 可以从一个或多个远程[模型上下文协议 (MCP)](https://modelcontextprotocol.io/) 服务器拉取工具。在您的[工作区](/langsmith/administration-overview#workspaces)设置中配置 MCP 服务器和请求头。Fleet 会自动发现工具并在调用它们时应用配置的请求头。更多信息，请参阅[远程 MCP 服务器](/langsmith/fleet/remote-mcp-servers)页面。

<Note icon="wand" iconType="regular">
  Fleet 支持每个代理使用自定义模型。更多信息，请参阅[自定义模型](/langsmith/fleet/essentials#custom-models)。
</Note>

### 添加密钥

要添加密钥：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，导航到 <Icon icon="settings" /> **设置**，然后转到 **密钥** 选项卡。
1. 选择 **添加密钥**，输入密钥的 **名称**（例如，`OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY`）以及您的密钥作为 **值**。

    <Note>
    确保密钥名称与您的模型提供商期望的环境变量名称匹配。
    </Note>

1. 选择 **保存密钥**。

## 使用情况和支出限额

**使用情况** 页面让工作区管理员能够查看 Fleet 支出，并为代理和用户设置支出限额。此页面仅对具有 `fleet:read-admin-config` 权限的用户可见。

### 查看当前支出

**使用情况** 页面显示您工作区在选定时间段（**过去 7 天** 或 **过去 14 天**）内的总支出，以及总线程数和总运行次数。

每日支出图表提供了所选期间成本的可视化细分。**细分** 部分允许您以两种方式查看支出详情：

- **按代理**：查看每个代理的总成本、运行次数、首次和最后使用日期、所有者以及每周限额。
- **按用户**：查看每个用户的支出和活动。

### 设置支出限额

支出限额让您可以控制代理和用户的支出额度。管理支出限额需要 `fleet:write-admin-config` 权限。

#### 默认每周支出限额

在 **默认每周支出限额** 部分，您可以配置：

- **每个代理的默认限额（美元）**：设置适用于工作区中所有代理的默认每周支出限额。
- **每个用户的默认限额（美元）**：设置适用于工作区中所有用户的默认每周支出限额。

限额按周计算，并在每周一重置。

#### 覆盖单个代理和用户的限额

您可以覆盖单个代理或用户的默认支出限额，以设置自定义的每周限额。

#### 支出限额行为

- 对支出限额的更改可能需要几分钟时间才能传播到所有正在运行的代理。
- 支出限额在每次运行开始时进行检查。如果运行开始时使用量低于限额，即使最终成本超过限额，也将允许其完成。
- 支出计算基于跟踪记录。删除跟踪记录将影响报告的使用情况和支出执行。
