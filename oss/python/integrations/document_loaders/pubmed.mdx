>[PubMed®](https://pubmed.ncbi.nlm.nih.gov/) 由 `美国国家生物技术信息中心、国家医学图书馆` 维护，包含超过 3500 万条来自 `MEDLINE`、生命科学期刊和在线书籍的生物医学文献引文。引文可能包含指向 `PubMed Central` 和出版商网站全文内容的链接。

```python
from langchain_community.document_loaders import PubMedLoader
```

```python
loader = PubMedLoader("chatgpt")
```

```python
docs = loader.load()
```

"背景：ChatGPT 是一个大型语言模型，在医学、法律和商业等领域的专业考试中表现良好。然而，目前尚不清楚 ChatGPT 在评估医生专业素养和情境判断的考试中表现如何。\n目的：我们评估了 ChatGPT 在情境判断测试中的表现：这是一项英国所有最后一年医学生都必须参加的全国性考试。该考试旨在评估沟通、团队合作、患者安全、优先级排序技能、专业素养和伦理等属性。\n方法：将英国基金会项目办公室的 2023 年情境判断测试练习考试的所有题目输入 ChatGPT。对于每个题目，记录 ChatGPT 的答案和理由，并根据英国基金会项目办公室的官方评分模板进行评估。根据评分表中提供的理由所引用的领域，将题目分类到《良好医疗实践》的各个领域。没有明确领域关联的题目由审阅者筛选，并分配一个或多个领域。评估了 ChatGPT 的整体表现及其在《良好医疗实践》各领域的表现。\n结果：总体而言，ChatGPT 表现良好，在情境判断测试中得分 76%，但只有少数题目（9%）获得满分，这可能反映了 ChatGPT 在情境判断方面可能存在的缺陷，或考试本身题目间推理的不一致（或两者兼有）。ChatGPT 在《良好医疗实践》为医生概述的 4 个领域中表现出一致的性能。\n结论：需要进一步研究，以了解大型语言模型（如 ChatGPT）在医学教育中的潜在应用，包括标准化题目和为评估专业素养和伦理的考试提供一致的理由。"
