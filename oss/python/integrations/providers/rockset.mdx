>[Rockset](https://rockset.com/product/) 是一个实时分析数据库服务，用于大规模提供低延迟、高并发的分析查询。它在结构化和半结构化数据上构建了 Converged Index™，并为向量嵌入提供了高效的存储。其支持在无模式数据上运行 SQL 的特性，使其成为运行带元数据过滤的向量搜索的完美选择。

## 安装与设置

确保您拥有 Rockset 账户，并前往 Web 控制台获取 API 密钥。详情可在[网站](https://rockset.com/docs/rest-api/)上找到。

<CodeGroup>
```bash pip
pip install rockset
```

```bash uv
uv add rockset
```
</CodeGroup>
