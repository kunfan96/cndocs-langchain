## 法律与合规

#### *LangSmith（包括其欧盟实例）遵守哪些隐私和数据保护框架？*

LangSmith 遵守《通用数据保护条例》（GDPR）以及适用于 LangSmith 服务的其他法律法规。我们还获得了 SOC 2 Type 2 认证，并符合 HIPAA 要求。您可以在 [trust.langchain.com](https://trust.langchain.com) 请求有关我们安全策略和态势的更多信息。如果您希望与我们签署数据处理附录（DPA），请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队。请注意，我们仅与企业计划的客户签订业务合作协议（BAA）。

#### *我的公司不在欧盟，我仍然可以将数据托管在那里吗？*

是的，您可以将 LangSmith 数据托管在欧盟实例中，这与您的所在地无关。

#### *你们在欧盟有可以签订合同的法人实体吗？*

我们目前在欧盟没有用于客户签约的法人实体。

#### *如果我选择欧盟区域，是否适用不同的法律条款？*

欧盟和美国区域的条款是相同的。

## 功能

#### *如何使用欧盟实例？*

请按照[账户和 API 密钥设置指南](/langsmith/create-account-api-key)创建一个账户和一个 API 密钥（确保在下拉菜单中将区域更改为欧盟）。

#### *美国和欧盟的云托管 LangSmith 在功能上有什么区别吗？*

根据功能的不同，每个区域的发布可能存在轻微延迟。除此之外，它们在功能上是等效的——美国支持的所有功能在欧盟也支持，反之亦然。

#### *一个组织可以在不同区域拥有工作区吗？*

LangSmith 目前不支持此功能，但如果您感兴趣，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队并分享您的用例。

#### *我可以将一个欧盟组织连接到一个美国组织并共享计费吗？*

LangSmith 目前不支持此功能，但如果您感兴趣，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队并分享您的用例。

#### *哪些数据将存储在我选择的区域？*

有关详细信息，请参阅[云架构参考](/langsmith/cloud#cloud-architecture-and-scalability)。

#### *如何查看我组织的区域？*

检查您的 URL——任何在 [https://eu.smith.langchain.com](https://eu.smith.langchain.com) 上的组织都在欧盟的 GCP 上。在 [https://smith.langchain.com](https://smith.langchain.com) 上的组织在美国的 GCP 上，而在 [https://aws.smith.langchain.com](https://aws.smith.langchain.com) 上的组织在美国的 AWS 上。

#### *我可以将我的组织从美国切换到欧盟，或反之亦然吗？*

我们目前不支持区域间迁移，但如果您对此功能感兴趣，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队。

## 计划与定价

#### *欧盟区域在所有 LangSmith 计划中都可用吗？*

是的，您可以在所有计划（包括免费计划）中注册欧盟区域。

#### *欧盟区域的定价与美国区域不同吗？*

不，欧盟和美国区域的定价是相同的。

#### *如果我使用欧盟区域，支付使用什么货币？*

所有 LangSmith 计划均以美元支付。
