>[Parallel](https://platform.parallel.ai/) 是一个为 LLM 和 AI 应用构建的实时网络搜索和内容提取平台。

`ParallelFindAllTool` 调用 Parallel 的 [FindAll API](https://docs.parallel.ai/findall-api/findall-quickstart) 进行实体发现。给定一个自然语言目标和一系列布尔匹配条件，它会返回满足每个条件的排名候选项。

### 凭证

前往 [Parallel](https://platform.parallel.ai) 注册并生成 API 密钥。在您的环境中设置 `PARALLEL_API_KEY`：

```python
import getpass
import os

if not os.environ.get("PARALLEL_API_KEY"):
    os.environ["PARALLEL_API_KEY"] = getpass.getpass("Parallel API key:\n")
```

## 实例化

`generator` 是一个工具级设置。使用 `"preview"`（免费，上限为 10 个候选项）进行快速迭代；切换到 `"base"`（默认）、`"core"` 或 `"pro"` 以获得更高质量的运行。

```python
from langchain_parallel import ParallelFindAllTool

tool = ParallelFindAllTool(generator="preview")
```

## 调用

### 快速发现（preview 生成器）

`preview` 生成器在几秒内返回，上限为 10 个候选项。`match_limit` 是必需的；对于 `preview`，它必须在 `[5, 10]` 范围内。

```python
from langchain_parallel import FindAllMatchCondition

result = await tool.ainvoke({
    "objective": "Pure-play public LLM API providers",
    "entity_type": "company",
    "match_conditions": [
        FindAllMatchCondition(
            name="public_us",
            description="Company is publicly traded on a US exchange",
        ),
        FindAllMatchCondition(
            name="llm_api_revenue",
            description="Primary revenue is selling LLM inference via API",
        ),
    ],
    "match_limit": 5,
})

for c in result["candidates"]:
    print(c["name"], "—", c["url"])
```

```text
Anthropic — https://www.anthropic.com
OpenAI — https://www.openai.com
...
```

### 更高质量的运行

切换到 `"base"`、`"core"` 或 `"pro"` 以获得高达 1000 的 `match_limit`。这些运行需要几分钟时间；工具会轮询直到运行达到终止状态（`completed`、`cancelled` 或 `failed`）。

```python
deep = ParallelFindAllTool(generator="core")

result = await deep.ainvoke({
    "objective": "Independent solar-installer companies based in the EU",
    "entity_type": "company",
    "match_conditions": [
        FindAllMatchCondition(
            name="eu_hq",
            description="Headquartered in an EU country",
        ),
        FindAllMatchCondition(
            name="residential_solar_pv",
            description="Primarily installs residential solar PV",
        ),
    ],
    "match_limit": 50,
})
```

### 排除已见过的候选项

传递 `exclude_list=[FindAllExcludeEntry(name=..., url=...)]` 以丢弃您已处理过的候选项。`name` 和 `url` 都是必需的。

```python
from langchain_parallel import FindAllExcludeEntry

result = await tool.ainvoke({
    "objective": "Pure-play public LLM API providers",
    "entity_type": "company",
    "match_conditions": [
        FindAllMatchCondition(
            name="llm_api_revenue",
            description="Primary revenue is selling LLM inference via API",
        ),
    ],
    "match_limit": 5,
    "exclude_list": [
        FindAllExcludeEntry(name="OpenAI", url="https://www.openai.com"),
        FindAllExcludeEntry(name="Anthropic", url="https://www.anthropic.com"),
    ],
})
```

### 取消

`cancel()` 通过 id 中止正在进行的运行。该 id 会返回给启动运行的调用者；如果您在长时间运行的任务中使用 `tool.ainvoke(...)` 启动了它，请在等待完成之前捕获运行中的 `findall_id`。

```python
# from another task / handler:
tool.cancel(findall_id)        # sync
await tool.acancel(findall_id) # async
```

### 参数

#### 必需

- `objective`：要查找内容的自然语言描述。
- `entity_type`：描述候选项类别的简短名词（`"company"`、`"researcher"`、`"product"` 等）。
- `match_conditions`：`FindAllMatchCondition(name=..., description=...)` 的列表。每个条件的两个字段都是必需的。
- `match_limit`：`[5, 1000]` 范围内的整数。`preview` 生成器会进一步将其上限设为 10。

#### 可选

- `exclude_list`：`FindAllExcludeEntry(name=..., url=...)` 的列表，用于跳过。
- `webhook`：`FindAllWebhook(url=..., event_types=[...])` 用于接收运行/候选项事件。
- `metadata`：持久化在运行上的自由格式元数据。
- `timeout`：轮询超时时间（秒）（默认 600）。

## 链式调用

将工具绑定到任何支持工具调用的聊天模型，并使用 [`create_agent`](/oss/python/langchain/agents) 驱动代理：

```python
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

llm = init_chat_model(model="claude-haiku-4-5", model_provider="anthropic")
agent = create_agent(model=llm, tools=[tool])

agent.invoke({"messages": [("human", "Find me a few independent EU solar installers.")]})
```

```python

    "candidates": [
        {
            "candidate_id": "cand_abc",
            "name": "Acme Solar",
            "url": "https://acmesolar.example",
            "description": "...",
            "match_status": "matched",  # or "generated" / "unmatched"
            "output": {
                "<condition_name>": {
                    "type": "match_condition",
                    "value": True,
                    "is_matched": True,
                },
            },
            "basis": [...],  # citations + reasoning per output field
        },
    ],
    "run": {...},          # status info
    "last_event_id": "...",
}
```
