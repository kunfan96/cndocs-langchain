以下是将HuggingFace推理模型作为大语言模型调用的示例：

```bash npm
npm install @langchain/community @langchain/core @huggingface/inference@4
```

<Tip>
我们正在统一所有包中的模型参数。现在建议使用 `model` 代替 `modelName`，使用 `apiKey` 代替API密钥。
</Tip>

```typescript
import { HuggingFaceInference } from "@langchain/community/llms/hf";

const model = new HuggingFaceInference({
  model: "gpt2",
  apiKey: "YOUR-API-KEY", // 在Node.js中默认为process.env.HUGGINGFACEHUB_API_KEY
});
const res = await model.invoke("1 + 1 =");
console.log({ res });
```
