>[Robocorp](https://robocorp.com/) 帮助构建和运行可在任何地方、任何规模无缝运行的 Python 工作程序。


## 安装与设置

您需要安装 `langchain-robocorp` Python 包：

<CodeGroup>
```bash pip
pip install langchain-robocorp
```

```bash uv
uv add langchain-robocorp
```
</CodeGroup>

您需要一个运行中的 `动作服务器` 实例，以便从您的代理应用程序进行通信。
请参阅 [Robocorp 快速入门](https://github.com/robocorp/robocorp#quickstart) 了解如何设置动作服务器并创建您的动作。

您可以使用动作服务器的 `new` 命令来引导一个新项目。

```bash
action-server new
cd ./your-project-name
action-server start
```

## 工具

```python
from langchain_robocorp.toolkits import ActionServerRequestTool
```
