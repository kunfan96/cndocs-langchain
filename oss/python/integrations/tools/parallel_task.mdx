>[Parallel](https://platform.parallel.ai/) 是一个为 LLM 和 AI 应用构建的实时网络搜索和内容提取平台。

[Task API](https://docs.parallel.ai/task-api/task-quickstart) 在分层处理器菜单（`lite` → `ultra`，以及匹配的 `-fast` 变体）上运行研究级任务。`langchain-parallel` 将其暴露为四个 LangChain 接口，全部在此页面上，以便您为工作负载选择合适的接口。

## 我应该使用哪个接口？

- **一个临时问题，可由代理调用**：`ParallelTaskRunTool`（`BaseTool`）。
- **一个长时间运行、多来源的报告**：`ParallelDeepResearch`（`Runnable`）。
- **对列表进行批量丰富，具有类型化的输入和输出**：`ParallelEnrichment`（`Runnable`）。
- **需要完全控制运行信封的底层批处理**：`ParallelTaskGroup`（普通类）。

所有四个接口默认使用 `-fast` 处理器变体（在相似精度下，比相应的非快速层级快 2-5 倍）。当延迟不如最高质量重要时，请去掉 `-fast` 后缀。有关完整菜单，请参阅[选择处理器](https://docs.parallel.ai/task-api/guides/choose-a-processor)。

### 凭证

前往 [Parallel](https://platform.parallel.ai) 注册并生成 API 密钥。在您的环境中设置 `PARALLEL_API_KEY`：

```python
import getpass
import os

if not os.environ.get("PARALLEL_API_KEY"):
    os.environ["PARALLEL_API_KEY"] = getpass.getpass("Parallel API key:\n")
```

## ParallelTaskRunTool

`ParallelTaskRunTool` 是一个可由代理调用的 `BaseTool`。它同步运行一个任务，并返回结构化的 `output`、按字段的 `basis` 引用以及 `run_id`。

```python
from langchain_parallel import ParallelTaskRunTool

tool = ParallelTaskRunTool()
result = tool.invoke({"input": "Who founded SpaceX, in one sentence?"})

print(result["output"]["content"])
print("run_id:", result["run"]["run_id"])
```

`result["output"]` 始终是一个字典；答案文本位于 `result["output"]["content"]`，按字段的引用位于 `result["output"]["basis"]`。传递 `task_output_schema` 可以让 `content` 以解析后的 pydantic 形状的字典形式到达，而不是自由文本字符串：

```python
from pydantic import BaseModel, Field

class FounderFact(BaseModel):
    founder: str = Field(description="Full name of the founder")
    year: int = Field(description="Year the company was founded")

structured = ParallelTaskRunTool(task_output_schema=FounderFact)
res = structured.invoke({"input": "Who founded SpaceX and in what year?"})

print(res["output"]["content"])
print(res["output"]["basis"])  # citations + reasoning + confidence per field
```

```text
{'founder': 'Elon Musk', 'year': 2002}
[{'field': 'founder', 'citations': [...], 'reasoning': '...', 'confidence': 'high'}, ...]
```

### parse_basis：引用 + 低置信度字段

每个关心置信度的消费者最终都会编写相同的样板代码来遍历结果以获取引用、低置信度字段和 `interaction_id`。`parse_basis()` 为您完成此操作：

```python
from langchain_parallel import parse_basis

parsed = parse_basis(res)
print("citations per field:", {f: len(c) for f, c in parsed["citations_by_field"].items()})
print("low-confidence fields:", parsed["low_confidence_fields"])
print("interaction_id:", parsed["interaction_id"])
```

### 多轮链接

结果字典在顶层显示 `interaction_id`。在下一次调用中将其作为 `previous_interaction_id` 传递，以跨轮次链接上下文：

```python
first = tool.invoke({"input": "Who founded SpaceX?"})
followup = tool.invoke({
    "input": "And what year was it founded?",
    "previous_interaction_id": first["interaction_id"],
})
```

## ParallelDeepResearch

`ParallelDeepResearch` 是一个 `Runnable`。它默认使用 `pro-fast`（“探索性网络研究”的 `-fast` 变体）。对于最彻底的多来源报告，请传递 `processor="ultra"`。

```python
from langchain_parallel import ParallelDeepResearch

research = ParallelDeepResearch()
result = research.invoke("Summarize the state of net-energy-gain fusion research as of 2026.")
print(result["output"]["content"])
```

<Note>
    深度研究运行不是即时的。`pro-fast` 通常需要几分钟；`pro` 和 `ultra` 可能需要更长时间。对于生产用途，请设置 webhook（参见 [Webhook 签名验证](#webhook-signature-verification)），而不是在 `invoke` 上阻塞。
</Note>

对于类型化的深度研究，请传递 `output_schema`：

```python
class CityFact(BaseModel):
    capital: str
    population_millions: float

typed = ParallelDeepResearch(output_schema=CityFact)
out = typed.invoke("Capital and population (in millions) of France?")
print(out["output"]["content"])
```

## ParallelTaskGroup

`ParallelTaskGroup` 创建一个任务组，扇出运行并收集结果。当您需要对批处理信封进行细粒度控制时直接使用它；否则，对于类型化的批量运行，请优先使用 `ParallelEnrichment`。

```python
from langchain_parallel import ParallelTaskGroup

group = ParallelTaskGroup()
results = group.run([
    "Founder of Anthropic? One sentence.",
    "Founder of OpenAI? One sentence.",
])

for r in results:
    print(r["output"]["content"])
```

`ParallelTaskGroup` 暴露 `run`（同步）和 `arun`（异步）。延迟由批处理中最慢的运行和所选处理器决定——`lite-fast` 通常在几秒内解决，更高层级则需要几分钟。

## ParallelEnrichment

`ParallelEnrichment` 包装了 `ParallelTaskGroup`，并使用从您的输入/输出 pydantic 模式构建的 `default_task_spec`。它将 pydantic 实例强制转换为字典，扇出批处理，并按输入顺序返回结果。

```python
from langchain_parallel import ParallelEnrichment

class CompanyInput(BaseModel):
    company: str = Field(description="Company name")

class CompanyOutput(BaseModel):
    headquarters: str
    founding_year: int

enricher = ParallelEnrichment(
    input_schema=CompanyInput,
    output_schema=CompanyOutput,
)
results = enricher.invoke([
    CompanyInput(company="Anthropic"),
    {"company": "OpenAI"},
])

for r in results:
    print(r["output"]["content"])
```

`ParallelEnrichment` 会阻塞，直到每个输入都已解决。使用默认的 `core-fast` 处理器，对于非平凡的批处理，预计需要几分钟；对于简短字段，请传递更快的处理器，或者对于大批处理，在后台工作器中运行。

## build_task_spec

`build_task_spec` 接受 pydantic 类、原始 JSON 模式字典或文本描述，并返回一个准备用于 `client.task_run.create` 或 `add_runs(default_task_spec=...)` 的 `TaskSpec` 字典。当您想要完全控制 `ParallelTaskRunTool` 或 `ParallelTaskGroup` 上的运行信封时使用它。

```python
from langchain_parallel import build_task_spec

spec = build_task_spec(input_schema=CompanyInput, output_schema=CompanyOutput)
print(list(spec.keys()))  # ['output_schema', 'input_schema']
```

## BYOMCP：自带 MCP 服务器

`ParallelTaskRunTool` 和 `ParallelDeepResearch` 接受 `mcp_servers=[McpServer(...)]`，以向运行暴露 Streamable-HTTP MCP 端点。

```python
from langchain_parallel import McpServer

mcp = McpServer(
    name="my_internal_mcp",
    url="https://example.com/mcp",
    headers={"Authorization": "Bearer ..."},
)

tool_with_mcp = ParallelTaskRunTool(mcp_servers=[mcp])
result = tool_with_mcp.invoke({"input": "What's our latest internal release?"})
```

## Webhook 签名验证

长时间运行的任务可以通过 webhook 交付结果。使用 `verify_webhook` 验证签名（标准 Webhook 方案：对 `<webhook-id>.<webhook-timestamp>.<body>` 进行 HMAC-SHA256，base64 编码，`v1,<sig>` 并带有重放保护）。有关交付合同，请参阅 [webhook 设置](https://docs.parallel.ai/resources/webhook-setup)。

```python
from langchain_parallel import verify_webhook

ok = verify_webhook(
    body,
    webhook_id=request.headers["webhook-id"],
    webhook_timestamp=request.headers["webhook-timestamp"],
    webhook_signature=request.headers["webhook-signature"],
    secret=os.environ["PARALLEL_WEBHOOK_SECRET"],
)
if not ok:
    raise PermissionError("invalid webhook signature")
```

## 链接

将 `ParallelTaskRunTool` 绑定到任何工具调用聊天模型，并使用 [`create_agent`](/oss/python/langchain/agents) 驱动代理：

```python
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

llm = init_chat_model(model="claude-opus-4-7")
agent = create_agent(model=llm, tools=[tool])

agent.invoke({"messages": [("human", "Look up Anthropic's founding year.")]})
```
