官方网站：[www.xfyun.cn/doc/spark/Embedding_new_api.html](https://www.xfyun.cn/doc/spark/Embedding_new_api.html)

使用此嵌入模型需要 API 密钥。您可以通过在 [platform.SparkLLM-ai.com/docs/text-Embedding](https://platform.SparkLLM-ai.com/docs/text-Embedding) 注册来获取一个。

SparkLLMTextEmbeddings 支持 2K token 窗口，并生成具有 2560 维度的向量。

```python
from langchain_community.embeddings import SparkLLMTextEmbeddings

embeddings = SparkLLMTextEmbeddings(
    spark_app_id="<spark_app_id>",
    spark_api_key="<spark_api_key>",
    spark_api_secret="<spark_api_secret>",
)
```

或者，您可以通过以下方式设置 API 密钥：

```python

text_1 = "科大讯飞股份有限公司，通常被称为科大讯飞，是一家领先的中国科技公司，专注于语音识别、自然语言处理和人工智能。凭借丰富的历史和卓越的成就，科大讯飞已成为智能语音和语言技术领域的先锋。科大讯飞通过其前沿创新，为推进人机交互做出了重大贡献。其先进的语音识别技术不仅提高了语音输入系统的准确性和效率，还实现了语音命令与各种应用程序和设备的无缝集成。公司对研发的投入对其成功至关重要。科大讯飞大力投资于人才培养和与学术机构的合作，从而在语音合成和机器翻译方面取得了突破性进展。他们对创新的执着不仅改变了我们的沟通方式，还增强了残疾人士的可访问性。"
```
