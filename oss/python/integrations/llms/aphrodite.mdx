[Aphrodite](https://github.com/PygmalionAI/aphrodite-engine) 是一个开源的大规模推理引擎，旨在为 [PygmalionAI](https://pygmalion.chat) 网站上的数千名用户提供服务。

* 采用 vLLM 的注意力机制，实现高吞吐量和低延迟
* 支持多种最先进的采样方法
* Exllamav2 GPTQ 内核，在较小的批处理大小下提供更好的吞吐量

本笔记本介绍如何在 LangChain 中使用带有 Aphrodite 的 LLM。

要使用，你应该已安装 `aphrodite-engine` Python 包。

```python
##安装集成所需的 langchain 包
pip install -qU langchain-community
```

```python
pip install -qU  aphrodite-engine==0.4.2
# pip list | grep aphrodite
```

```python
from langchain_community.llms import Aphrodite

llm = Aphrodite(
    model="PygmalionAI/pygmalion-2-7b",
    trust_remote_code=True,  # 对于 hf 模型是必需的
    max_tokens=128,
    temperature=1.2,
    min_p=0.05,
    mirostat_mode=0,  # 改为 2 以使用 mirostat
    mirostat_tau=5.0,
    mirostat_eta=0.1,
)

print(
    llm.invoke(
        '<|system|>进入角色扮演模式。你是春日步（"大阪"）。<|user|>嘿，大阪。介绍一下你自己。<|model|>'
    )
)
```

## 在 LLMChain 中集成模型

```python
from langchain_classic.chains import LLMChain
from langchain_core.prompts import PromptTemplate

template = """问题：{question}

答案：让我们一步一步思考。"""
prompt = PromptTemplate.from_template(template)

llm_chain = LLMChain(prompt=prompt, llm=llm)

question = "第一个宝可梦游戏发布的那一年，美国总统是谁？"

print(llm_chain.run(question))
```

## 分布式推理

Aphrodite 支持分布式张量并行推理和服务。

要使用 LLM 类运行多 GPU 推理，请将 `tensor_parallel_size` 参数设置为你想要使用的 GPU 数量。例如，要在 4 个 GPU 上运行推理

```python
from langchain_community.llms import Aphrodite

llm = Aphrodite(
        model="PygmalionAI/mythalion-13b",
        tensor_parallel_size=4,
        trust_remote_code=True,  # 对于 hf 模型是必需的
)

llm("人工智能的未来是什么？")
```
