[Jenkins](https://www.jenkins.io/) 是一个开源自动化平台，使软件团队能够简化其开发工作流程。它在 DevOps 社区中被广泛采用，作为通过 CI/CD 管道自动化构建、测试和部署应用程序的工具。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-jenkins
```

```bash uv
uv add langchain-jenkins
```
</CodeGroup>
