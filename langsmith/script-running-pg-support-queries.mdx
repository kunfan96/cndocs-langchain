此 Helm 仓库包含用于生成 LangSmith UI 当前不直接支持的输出的查询（例如，在单个查询中获取多个组织的跟踪计数）。

此命令接受一个包含嵌入式名称和密码的 PostgreSQL 连接字符串（可以从密钥管理器的调用中传入），并从输入文件执行查询。在下面的示例中，我们使用 `support_queries/postgres` 目录中的 `pg_get_trace_counts_daily.sql` 输入文件。

## 前提条件

确保您已准备好以下工具/项目。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. PostgreSQL 客户端

   * [https://www.postgresql.org/download/](https://www.postgresql.org/download/)

3. PostgreSQL 数据库连接：

   * 主机
   * 端口
   * 用户名
     * 如果使用捆绑版本，此为 `postgres`
   * 密码
     * 如果使用捆绑版本，此为 `postgres`
   * 数据库名称
     * 如果使用捆绑版本，此为 `postgres`

4. 从您将运行迁移脚本的机器到 PostgreSQL 数据库的连接性。

   * 如果您使用捆绑版本，可能需要将 postgresql 服务端口转发到您的本地机器。
   * 运行 `kubectl port-forward svc/langsmith-postgres 5432:5432` 将 postgresql 服务端口转发到您的本地机器。

5. 用于运行支持查询的脚本

   * 下载 [PostgreSQL 支持查询脚本](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/run_support_query_pg.sh)

## 运行查询脚本

运行以下命令以执行所需的查询：

```bash
sh run_support_query_pg.sh <postgres_url> --input path/to/query.sql
```

例如，如果您使用带有端口转发的捆绑版本，命令可能如下所示：

```bash
sh run_support_query_pg.sh "postgres://postgres:postgres@localhost:5432/postgres" --input support_queries/pg_get_trace_counts_daily.sql
```

这将输出按工作区 ID 和组织 ID 划分的每日跟踪计数。要将此输出到文件，请添加标志 `--output path/to/file.csv`

## 导出使用数据

所有导出方法产生相同的数据：所有工作区和组织中的 LangSmith 跟踪计数、LangSmith Deployments 节点使用情况和 Fleet 运行计数。

<Note>
UI 和 API 导出需要同时满足以下条件：

- `organization:manage` 权限。
- 调用者的电子邮件必须列在 `USAGE_EXPORT_ADMIN_EMAILS` 中，或者 `ORG_ADMINS_INSTALLATION_USAGE_EXPORT_ENABLED` 必须设置为 `true`。

```env
USAGE_EXPORT_ADMIN_EMAILS='["admin@example.com", "admin2@example.com"]'
ORG_ADMINS_INSTALLATION_USAGE_EXPORT_ENABLED=true
```
</Note>

### 从 UI 导出（推荐）

1. 导航至 **设置** > **使用情况和计费** > **使用情况导出**。
2. 点击 **导出使用数据**。
3. 一个包含所有使用数据的 ZIP 文件将开始下载。

### 通过 API 导出

如果您希望以编程方式导出使用数据，可以直接调用导出 API 端点。

```bash
curl -OJ \
  -H "X-API-Key: <your_api_key>" \
  https://<langsmith_url>/api/v1/orgs/current/usage/backfill-export
```

### 通过 SQL 脚本导出

您也可以直接对 PostgreSQL 数据库运行 SQL 脚本以导出使用数据。这需要数据库访问凭据——不适用应用程序级权限。

要导出跟踪使用情况（需要 Helm chart 版本 0.11.4 或更高版本）：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_traces_full_export.sql \
  --output ls_export.csv
```

要导出节点使用情况（需要 Helm chart 版本 0.11.4 或更高版本）：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_nodes_full_export.sql \
  --output lgp_export.csv
```

要导出 Fleet 运行计数（需要 Helm chart 版本 0.13.25 或更高版本）：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_agent_builder_full_export.sql \
  --output ab_export.csv
```

要导出使用情况快照（每日实体计数，如工作区、项目、数据集、提示和活跃用户）：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_snapshots_full_export.sql \
  --output usage_snapshots_export.csv
```
