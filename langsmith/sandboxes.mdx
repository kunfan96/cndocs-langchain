沙盒是隔离环境，允许代理安全地执行潜在风险操作——例如运行任意代码或与文件系统交互——而不会影响您的主要基础设施。

<SandboxPreview />

从 [LangSmith 主页](https://smith.langchain.com) 中，选择 **沙盒** 来管理所有沙盒资源。

![沙盒概述页面](/images/langsmith/sandboxes/sb-overview.png)

## 资源

<CardGroup cols={2}>

<Card title="快照" icon="camera" href="/langsmith/sandbox-snapshots">
  从 Docker 镜像构建文件系统镜像或捕获正在运行的沙盒，然后从中启动沙盒。
</Card>

<Card title="服务 URL" icon="globe" href="/langsmith/sandbox-service-urls">
  通过经过身份验证的 URL 访问在沙盒内运行的 HTTP 服务。
</Card>

<Card title="身份验证代理" icon="shield-lock" href="/langsmith/sandbox-auth-proxy">
  在不硬编码密钥的情况下，将凭据注入出站 API 请求。
</Card>

<Card title="CLI" icon="terminal-2" href="/langsmith/sandbox-cli">
  从命令行构建快照、管理沙盒、打开控制台以及隧道传输 TCP 端口。
</Card>

<Card title="SDK 用法" icon="code" href="/langsmith/sandbox-sdk">
  使用 Python 或 TypeScript SDK 以编程方式创建和管理沙盒。
</Card>

</CardGroup>
