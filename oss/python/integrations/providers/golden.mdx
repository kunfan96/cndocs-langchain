>[Golden](https://golden.com) 提供了一套自然语言 API，用于通过 Golden 知识图谱进行查询和丰富数据，例如查询如：`OpenAI 的产品`、`获得 A 轮融资的生成式人工智能公司`以及`投资的说唱歌手`可用于检索相关实体的结构化数据。
>
>`golden-query` langchain 工具是 [Golden Query API](https://docs.golden.com/reference/query-api) 之上的一个封装器，它支持对这些结果进行编程访问。
>更多信息请参阅 [Golden Query API 文档](https://docs.golden.com/reference/query-api)。

## 安装与设置
- 前往 [Golden API 文档](https://docs.golden.com/) 以了解 Golden API 的概况。
- 从 [Golden API 设置](https://golden.com/settings/api) 页面获取您的 API 密钥。
- 将您的 API 密钥保存到 GOLDEN_API_KEY 环境变量中

## 封装器

### 实用工具

存在一个 GoldenQueryAPIWrapper 实用工具，它封装了此 API。要导入此实用工具：

```python
from langchain_community.utilities.golden_query import GoldenQueryAPIWrapper
```

有关此封装器的更详细演练，请参阅[此笔记本](/oss/python/integrations/tools/golden_query)。

### 工具

您也可以轻松地将此封装器作为工具加载（以与代理一起使用）。
您可以这样做：
```python
from langchain_community.agent_toolkits.load_tools import load_tools
tools = load_tools(["golden-query"])
```

有关工具的更多信息，请参阅[工具](/oss/python/integrations/tools)。
