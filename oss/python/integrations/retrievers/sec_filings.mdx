>[SEC文件](https://www.sec.gov/edgar)是提交给美国证券交易委员会（SEC）的财务报表或其他正式文件。上市公司、某些内部人士和经纪交易商需要定期提交`SEC文件`。投资者和金融专业人士依赖这些文件获取他们正在评估投资的公司的信息。
>
>`SEC文件`数据由[Kay.ai](https://kay.ai)和[Cybersyn](https://www.cybersyn.com/)通过[Snowflake Marketplace](https://app.snowflake.com/marketplace/providers/GZTSZAS2KCS/Cybersyn%2C%20Inc)提供支持。

## 设置

首先，您需要安装`kay`包。您还需要一个API密钥：您可以在[https://kay.ai](https://kay.ai/)免费获取一个。获得API密钥后，必须将其设置为环境变量`KAY_API_KEY`。

在此示例中，我们将使用`KayAiRetriever`。有关其接受参数的更详细信息，请查看[kay笔记本](/oss/python/integrations/retrievers/kay)。

```python
# 为Kay和OpenAI设置API密钥
from getpass import getpass

KAY_API_KEY = getpass()
OPENAI_API_KEY = getpass()
```

## 示例

```python
from langchain_classic.chains import ConversationalRetrievalChain
from langchain_community.retrievers import KayAiRetriever
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-3.5-turbo")
retriever = KayAiRetriever.create(
    dataset_id="company", data_types=["10-K", "10-Q"], num_contexts=6
)
qa = ConversationalRetrievalChain.from_llm(model, retriever=retriever)
```

```python
questions = [
    "过去三个季度，英伟达的支出模式是什么？",
    # "可再生能源行业最近面临哪些挑战？",
]
chat_history = []

for question in questions:
    result = qa({"question": question, "chat_history": chat_history})
    chat_history.append((question, result["answer"]))
    print(f"-> **问题**: {question} \n")
    print(f"**答案**: {result['answer']} \n")
```
