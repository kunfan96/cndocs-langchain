本笔记本介绍如何在 LangChain 中使用 Xinference 嵌入模型。

## 安装

通过 PyPI 安装 `Xinference`：

```python
pip install -qU  "xinference[all]"
```

## 在本地或分布式集群中部署 Xinference

对于本地部署，运行 `xinference`。

要在集群中部署 Xinference，首先使用 `xinference-supervisor` 启动一个 Xinference 主节点。您也可以使用选项 -p 指定端口，-H 指定主机。默认端口是 9997。

然后，在您希望运行工作节点的每台服务器上使用 `xinference-worker` 启动 Xinference 工作节点。

您可以查阅 [Xinference](https://github.com/xorbitsai/inference) 的 README 文件以获取更多信息。

## 封装器

要在 LangChain 中使用 Xinference，您需要首先启动一个模型。您可以使用命令行界面 (CLI) 来完成：

```python
!xinference launch -n vicuna-v1.3 -f ggmlv3 -q q4_0
```

```text
模型 UID：915845ee-2a04-11ee-8ed4-d29396a3f064
```

系统会返回一个模型 UID 供您使用。现在您可以将 Xinference 嵌入模型与 LangChain 一起使用：

```python
from langchain_community.embeddings import XinferenceEmbeddings

xinference = XinferenceEmbeddings(
    server_url="http://0.0.0.0:9997", model_uid="915845ee-2a04-11ee-8ed4-d29396a3f064"
)
```

```python
query_result = xinference.embed_query("这是一个测试查询")
```

```python
doc_result = xinference.embed_documents(["文本 A", "文本 B"])
```

最后，当您不再需要使用该模型时，终止它：

```python
!xinference terminate --model-uid "915845ee-2a04-11ee-8ed4-d29396a3f064"
```
