**已弃用** 此 API 将于 2023-11-17 停止服务：[nla.zapier.com/start/](https://nla.zapier.com/start/)

>[Zapier 自然语言操作](https://nla.zapier.com/start/) 通过自然语言 API 接口，让你访问 Zapier 平台上的 5000 多个应用和 20000 多个操作。
>
>NLA 支持 `Gmail`、`Salesforce`、`Trello`、`Slack`、`Asana`、`HubSpot`、`Google Sheets`、`Microsoft Teams` 等应用，以及数千个其他应用：[zapier.com/apps](https://zapier.com/apps)
>`Zapier NLA` 处理所有底层 API 认证和从自然语言到 API 调用的转换，并为大语言模型返回简化输出。核心思想是，你或你的用户通过一个类似 OAuth 的设置窗口暴露一组操作，然后你可以通过 REST API 查询和执行这些操作。

NLA 提供 API Key 和 OAuth 两种方式来签署 NLA API 请求。

1. 服务端（API Key）：用于快速入门、测试以及 LangChain 仅使用开发者 Zapier 账户中暴露的操作（并使用开发者在 Zapier.com 上连接的账户）的生产场景。

2. 面向用户（OAuth）：用于你部署面向最终用户的应用程序，且 LangChain 需要访问最终用户在 Zapier.com 上暴露的操作和连接账户的生产场景。

为简洁起见，本快速入门主要关注服务端用例。跳转到 [使用 OAuth 访问令牌的示例](#example-using-oauth-access-token) 查看如何为面向用户的情况设置 Zapier 的简短示例。请查阅[完整文档](https://nla.zapier.com/start/)以获取完整的面向用户的 OAuth 开发者支持。

本示例介绍如何将 Zapier 集成与 `SimpleSequentialChain` 一起使用，然后与 `Agent` 一起使用。
代码如下：

```python
import os

# 从 https://platform.openai.com/ 获取
os.environ["OPENAI_API_KEY"] = os.environ.get("OPENAI_API_KEY", "")

# 登录后从 https://nla.zapier.com/docs/authentication/ 获取：
os.environ["ZAPIER_NLA_API_KEY"] = os.environ.get("ZAPIER_NLA_API_KEY", "")
```

## 使用 Agent 的示例

Zapier 工具可以与 Agent 一起使用。请参见下面的示例。

```python
from langchain.agents import create_agent
from langchain_community.agent_toolkits import ZapierToolkit
from langchain_community.utilities.zapier import ZapierNLAWrapper
from langchain_openai import OpenAI
```

```python
## 步骤 0. 暴露 gmail '查找邮件' 和 slack '发送频道消息' 操作

# 首先访问此处，登录，暴露（启用）这两个操作：https://nla.zapier.com/demo/start -- 对于此示例，可以将所有字段保留为 "Have AI guess"
# 在 oauth 场景中，你会获得自己的 <provider> id（而不是 'demo'），你需要先引导你的用户通过它
```

```python
llm = OpenAI(temperature=0)
zapier = ZapierNLAWrapper()
toolkit = ZapierToolkit.from_zapier_nla_wrapper(zapier)
agent = create_agent(
    model=llm,
    tools=toolkit.get_tools(),
)
```

```python
agent.invoke(
    {
        "input": "总结我收到的关于硅谷银行的最后一封邮件。将摘要发送到 slack 的 #test-zapier 频道。"
    }
)
```

## 使用 SimpleSequentialChain 的示例

如果你需要更明确的控制，请使用链，如下所示。

```python
from langchain_classic.chains import LLMChain, SimpleSequentialChain, TransformChain
from langchain_community.tools.zapier.tool import ZapierNLARunAction
from langchain_community.utilities.zapier import ZapierNLAWrapper
from langchain_core.prompts import PromptTemplate
from langchain_openai import OpenAI
```

```python
## 步骤 0. 暴露 gmail '查找邮件' 和 slack '发送直接消息' 操作

# 首先访问此处，登录，暴露（启用）这两个操作：https://nla.zapier.com/demo/start -- 对于此示例，可以将所有字段保留为 "Have AI guess"
# 在 oauth 场景中，你会获得自己的 <provider> id（而不是 'demo'），你需要先引导你的用户通过它

actions = ZapierNLAWrapper().list()
```

```python
## 步骤 1. gmail 查找邮件

GMAIL_SEARCH_INSTRUCTIONS = "Grab the latest email from Silicon Valley Bank"


def nla_gmail(inputs):
    action = next(
        (a for a in actions if a["description"].startswith("Gmail: Find Email")), None
    )
    return {
        "email_data": ZapierNLARunAction(
            action_id=action["id"],
            zapier_description=action["description"],
            params_schema=action["params"],
        ).run(inputs["instructions"])
    }


gmail_chain = TransformChain(
    input_variables=["instructions"],
    output_variables=["email_data"],
    transform=nla_gmail,
)
```

```python
## 步骤 2. 生成草稿回复

template = """You are an assisstant who drafts replies to an incoming email. Output draft reply in plain text (not JSON).

Incoming email:
{email_data}

Draft email reply:"""

prompt_template = PromptTemplate(input_variables=["email_data"], template=template)
reply_chain = LLMChain(llm=OpenAI(temperature=0.7), prompt=prompt_template)
```

```python
## 步骤 3. 通过 slack 直接消息发送草稿回复

SLACK_HANDLE = "@Ankush Gola"


def nla_slack(inputs):
    action = next(
        (
            a
            for a in actions
            if a["description"].startswith("Slack: Send Direct Message")
        ),
        None,
    )
    instructions = f"Send this to {SLACK_HANDLE} in Slack: {inputs['draft_reply']}"
    return {
        "slack_data": ZapierNLARunAction(
            action_id=action["id"],
            zapier_description=action["description"],
            params_schema=action["params"],
        ).run(instructions)
    }


slack_chain = TransformChain(
    input_variables=["draft_reply"],
    output_variables=["slack_data"],
    transform=nla_slack,
)
```

```python
## 最后，执行

overall_chain = SimpleSequentialChain(
    chains=[gmail_chain, reply_chain, slack_chain], verbose=True
)
overall_chain.run(GMAIL_SEARCH_INSTRUCTIONS)
```

## 使用 OAuth 访问令牌的示例

以下代码片段展示了如何使用获取的 OAuth 访问令牌初始化包装器。注意传入的参数与设置环境变量的区别。请查阅[认证文档](https://nla.zapier.com/docs/authentication/#oauth-credentials)以获取完整的面向用户的 OAuth 开发者支持。

开发者负责处理 OAuth 握手以获取和刷新访问令牌。

```python
llm = OpenAI(temperature=0)
zapier = ZapierNLAWrapper(zapier_nla_oauth_access_token="<在此处填入访问令牌>")
toolkit = ZapierToolkit.from_zapier_nla_wrapper(zapier)
agent = create_agent(
    model=llm,
    tools=toolkit.get_tools(),
)

agent.invoke({
    "input": "总结我收到的关于硅谷银行的最后一封邮件。将摘要发送到 slack 的 #test-zapier 频道。"
})
```
