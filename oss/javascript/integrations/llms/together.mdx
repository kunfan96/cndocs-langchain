这将帮助您开始使用 LangChain 的 Together AI 文本补全模型（LLM）。有关 `TogetherAI` 功能和配置选项的详细文档，请参阅 [API 参考](https://reference.langchain.com/javascript/langchain-community/llms/togetherai/TogetherAI)。

## 设置

要访问 `ChatTogetherAI` 模型，您需要创建一个 Together 账户，[获取 API 密钥](https://api.together.xyz/)，并安装 `@langchain/community` 集成包。

### 凭证

前往 [api.together.ai](https://api.together.ai/) 注册 TogetherAI 并生成 API 密钥。完成此操作后，设置 `TOGETHER_AI_API_KEY` 环境变量：

```bash
export TOGETHER_AI_API_KEY="your-api-key"
```

如果您想获得模型调用的自动跟踪，也可以通过取消注释下方内容来设置您的 [LangSmith](/langsmith/home) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain TogetherAI 集成位于 `@langchain/community` 包中：

<CodeGroup>
```bash npm
npm install @langchain/community @langchain/core
```
```bash yarn
yarn add @langchain/community @langchain/core
```
```bash pnpm
pnpm add @langchain/community @langchain/core
```
</CodeGroup>

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```typescript
import { TogetherAI } from "@langchain/community/llms/togetherai";

const llm = new TogetherAI({
  model: "meta-llama/Meta-Llama-3.1-8B-Instruct-Turbo",
  maxTokens: 256,
});
```
