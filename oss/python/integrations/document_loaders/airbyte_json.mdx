注意：`AirbyteJSONLoader` 已弃用。请改用 [`AirbyteLoader`](/oss/python/integrations/document_loaders/airbyte)。

>[Airbyte](https://github.com/airbytehq/airbyte) 是一个用于 ELT 管道的数据集成平台，可将 API、数据库和文件中的数据传输到数据仓库和数据湖。它拥有用于数据仓库和数据库的最大 ELT 连接器目录。

本文介绍如何将 Airbyte 中的任何源加载到本地 JSON 文件中，以便作为文档读取。

前提条件：
已安装 Docker Desktop。

步骤：

1) 从 GitHub 克隆 Airbyte - `git clone https://github.com/airbytehq/airbyte.git`

2) 切换到 Airbyte 目录 - `cd airbyte`

3) 启动 Airbyte - `docker compose up`

4) 在浏览器中，访问 [localhost:8000](http://localhost:8000)。系统会要求输入用户名和密码。默认情况下，用户名为 `airbyte`，密码为 `password`。

5) 设置任何您希望使用的源。

6) 将目标设置为本地 JSON，并指定目标路径 - 例如 `/json_data`。设置手动同步。

7) 运行连接。

7) 要查看创建了哪些文件，您可以导航至：`file:///tmp/airbyte_local`

8) 找到您的数据并复制路径。该路径应保存在下面的 `file` 变量中。它应以 `/tmp/airbyte_local` 开头。

```python
from langchain_community.document_loaders import AirbyteJSONLoader
```
