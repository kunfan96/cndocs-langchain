Cognee 实现了可扩展、模块化的 ECL（提取、认知、加载）流水线，允许您互联并检索过去的对话、文档和音频转录，同时减少幻觉、开发者工作量和成本。

Cognee 融合了图数据库和向量数据库，以揭示数据中隐藏的关系和新模式。您可以自动建模、加载和检索代表您业务领域的实体和对象，并分析它们的关系，从而发现仅靠向量存储或图存储都无法提供的洞察。

如果您有问题，请加入 cognee <a href="https://discord.gg/NQPKmU5CCg">Discord</a> 社区。

您看过 cognee 的 <a href="https://github.com/topoteretes/cognee-starter">入门仓库</a> 吗？快去看看吧！


## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-cognee
```

```bash uv
uv add langchain-cognee
```
</CodeGroup>
