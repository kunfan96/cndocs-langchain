<Note>
Google 的 `内置 AI 早期预览计划` 目前处于测试阶段。要申请访问权限或了解更多信息，请访问[此链接](https://developer.chrome.com/docs/ai/built-in)。
</Note>

ChromeAI 利用 Gemini Nano 直接在浏览器或 [工作线程](https://developer.mozilla.org/en-US/docs/Web/API/Worker) 中运行大语言模型，无需互联网连接。这使得运行更快、更私密的模型成为可能，数据永远不会离开用户的设备。

## 入门指南

一旦您获得该计划的访问权限，请按照 Google 提供的说明下载模型。

下载完成后，您可以在浏览器中开始使用 `ChromeAI`，如下所示：

```typescript
import { ChromeAI } from "@langchain/community/experimental/llms/chrome_ai";

const model = new ChromeAI({
  temperature: 0.5, // 可选，默认值为 0.5
  topK: 40, // 可选，默认值为 40
});

const response = await model.invoke("Write me a short poem please");

/*
  在月光编织其色彩的领域，
  梦想与秘密温柔交织的地方，
  有一个宁静与优雅的所在，
  夜晚的低语在此找到归宿。

  在星光璀璨的天幕之下，
  梦想展翅，忧虑消散，
  一个纯粹而真实的宁静港湾，
  心灵在此找到慰藉，如沐晨露。

  在这个梦想得以释放的领域，

  让我们漫步其中，迷失在其怀抱，
  在这片宁静的空间里找到慰藉。
*/
```

### 流式输出

`ChromeAI` 也支持流式输出：

```typescript
import { ChromeAI } from "@langchain/community/experimental/llms/chrome_ai";

const model = new ChromeAI({
  temperature: 0.5, // 可选，默认值为 0.5
  topK: 40, // 可选，默认值为 40
});

for await (const chunk of await model.stream("How are you?")) {
  console.log(chunk);
}
```
