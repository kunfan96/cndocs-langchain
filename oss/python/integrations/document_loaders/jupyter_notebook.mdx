>[Jupyter Notebook](https://en.wikipedia.org/wiki/Project_Jupyter#Applications)（前身为 `IPython Notebook`）是一个基于 Web 的交互式计算环境，用于创建笔记本文档。

本笔记本介绍如何将数据从 `Jupyter notebook (.ipynb)` 加载到 LangChain 适用的格式。

```python
from langchain_community.document_loaders import NotebookLoader
```

```python
loader = NotebookLoader(
    "example_data/notebook.ipynb",
    include_outputs=True,
    max_output_length=20,
    remove_newline=True,
)
```

`NotebookLoader.load()` 将 `.ipynb` 笔记本文件加载为 [`Document`](https://reference.langchain.com/python/langchain-core/documents/base/Document) 对象。

**参数**：

* `include_outputs`（布尔值）：是否在结果文档中包含单元格输出（默认为 False）。
* `max_output_length`（整数）：从每个单元格输出中包含的最大字符数（默认为 10）。
* `remove_newline`（布尔值）：是否从单元格源代码和输出中移除换行符（默认为 False）。
* `traceback`（布尔值）：是否包含完整的回溯信息（默认为 False）。

```python
loader.load()
```
