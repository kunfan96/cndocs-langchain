[AgentPhone](https://agentphone.to) 是一个面向 AI 代理的电话平台，通过一个简单的 API 提供消息传递、语音通话、电话号码管理和联系人管理功能。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-agentphone
```

```bash uv
uv add langchain-agentphone
```
</CodeGroup>

从 [agentphone.to](https://agentphone.to) 获取您的 API 密钥，并将其设置为环境变量：

```bash
export AGENTPHONE_API_KEY="your-api-key"
```

## 工具

有关可用工具（包括消息传递、语音通话、电话号码管理等）的详细信息，请参阅 [AgentPhone 工具包](/oss/python/integrations/tools/agentphone) 指南。
