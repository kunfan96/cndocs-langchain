通过使用 SDK 中的方法或 API 中的端点，您可以筛选运行以进行分析和导出。

## 过滤参数

| 键名                          | 描述                                                                                                                                                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `project_id` / `project_name` | 要从中获取运行的项目 - 可以是单个项目或项目列表。                                                                                                                                             |
| `trace_id`                    | 获取属于特定追踪的运行。                                                                                                                                                                                  |
| `run_type`                    | 要获取的[运行类型](/langsmith/run-data-format#run-types)，例如 `llm`、`chain`、`tool`、`retriever`。                                                                                                                              |
| `dataset_name` / `dataset_id` | 获取与指定数据集中示例行关联的运行。这对于在给定数据集上比较提示或模型非常有用。                                                                              |
| `reference_example_id`        | 获取与特定示例行关联的运行。这对于在给定输入上比较提示或模型非常有用。                                                                                                   |
| `parent_run_id`               | 获取作为给定运行子项的运行。这对于获取使用上下文管理器分组在一起的运行或获取代理轨迹非常有用。                                                                  |
| `error`                       | 获取出错或未出错的运行。                                                                                                                                                                                      |
| `run_ids`                     | 获取具有给定运行 ID 列表的运行。注意：**这将忽略所有其他过滤参数。**                                                                                                                             |
| `filter`                      | 获取匹配给定结构化过滤语句的运行。有关更多信息，请参阅下面的指南。                                                                                                                           |
| `trace_filter`                | 应用于追踪树中根运行的过滤器。这旨在与常规 `filter` 参数结合使用，让您根据追踪中根运行的属性过滤运行。                            |
| `tree_filter`                 | 应用于追踪树中其他运行（包括同级和子运行）的过滤器。这旨在与常规 `filter` 参数结合使用，让您根据追踪中任何运行的属性过滤运行。 |
| `is_root`                     | 仅返回根运行。                                                                                                                                                                                                         |
| `select`                      | 选择响应中要返回的字段。默认情况下，返回所有字段。有关可用字段，请参阅[运行数据格式](/langsmith/run-data-format)。                                                                                                                                              |
| `query` (_实验性功能_)        | 自然语言查询，可将您的查询转换为过滤语句。                                                                                                                                                   |

<Note>
**性能提示**：传递 `select` 参数并从列表中排除 `inputs` 和 `outputs` 可以显著提高查询性能并减小响应大小，尤其是对于大型运行。
</Note>

## 过滤查询语言

LangSmith 支持强大的过滤功能，使用过滤查询语言在获取运行时允许复杂的过滤操作。

过滤语法基于运行对象字段上的常见比较器。支持的比较器包括：

-   `gte`（大于或等于）
-   `gt`（大于）
-   `lte`（小于或等于）
-   `lt`（小于）
-   `eq`（等于）
-   `neq`（不等于）
-   `has`（检查运行是否包含标签或元数据 JSON 块）
-   `search`（在字符串字段中搜索子字符串）

此外，您可以通过 `and` 运算符组合多个比较。

这些可以应用于运行对象的字段，例如其 `id`、`name`、`run_type`、`start_time` / `end_time`、`latency`、`total_tokens`、`error`、`execution_order`、`tags`，以及通过 `feedback_key` 和 `feedback_score` 关联的任何反馈。
