从追踪视图中，您可以[并排比较两个追踪](#比较追踪)、[公开共享追踪](#共享追踪)以及[查看与追踪执行相关的服务器日志](#查看服务器日志)。

## 比较追踪

您可以从 [UI](https://smith.langchain.com) 中的两个区域开始比较追踪：

1. 从 **Tracing** 项目视图的 **Runs** 选项卡中，选择您想要比较的追踪旁边的复选框。然后，选择页面底部的 **Compare Runs** 以打开并排比较视图。
1. 当您正在查看某个追踪时，选择更多 <Icon icon="dots-vertical" /> 菜单以导航至 **Compare**。这将打开追踪运行表。选择您想要与原始追踪进行比较的追踪。侧面板将打开，其中两个追踪都已选中并处于并排比较视图中。

要停止比较，请关闭面板或点击面板右上角的 **Stop comparing**。

## 共享追踪

<Warning>
**公开共享追踪将使任何拥有链接的人都能访问它。请确保您没有共享敏感信息。**

如果您[自托管](/langsmith/self-hosted)或[混合](/langsmith/hybrid)部署的 LangSmith 位于 VPC 内，那么公共链接仅对在您的 VPC 内经过身份验证的成员可访问。为了增强安全性，我们建议将您的实例配置为仅对有权访问您网络的用户可访问的私有 URL。
</Warning>

要公开共享追踪：

1. 在 [UI](https://smith.langchain.com) 中打开任意追踪。
1. 点击追踪视图顶部更多 <Icon icon="dots-vertical" /> 菜单中的 **Share** 按钮。
1. 在出现的对话框中，复制公共链接。

共享的追踪对任何拥有链接的人都可访问，即使没有 LangSmith 帐户。他们可以查看追踪但不能编辑它。

要取消共享追踪，请使用以下任一方法：

1. 打开共享的追踪，点击追踪视图顶部工具栏中的 **Public**，然后在对话框中点击 **Unshare**。
1. 转到 **Settings** → **Shared URLs** 以查看所选工作区中所有公开共享的追踪。点击您想要取消共享的追踪旁边的 **Unshare**。

## 查看服务器日志

<Note>
查看追踪的服务器日志仅适用于 [Cloud SaaS](/langsmith/cloud) 和[完全自托管](/langsmith/self-hosted)部署选项。
</Note>

当查看由 LangSmith 中的运行生成的追踪时，您可以直接从追踪视图访问相关的服务器日志。

在追踪视图中，使用右上角的 **See Logs** 按钮，该按钮位于 **Run in Studio** 按钮旁边。

点击此按钮将带您前往 LangSmith 中相关部署的服务器日志视图。

服务器日志视图显示来自以下两方面的日志：

- **Agent Server 自身的操作日志**：内部服务器操作、API 调用和系统事件
- **用户应用程序日志**：在您的图中编写的日志，使用：
  - Python：使用 `logging` 或 `structlog` 库。
  - JavaScript：使用从 `@langchain/langgraph-sdk/logging` 重新导出的 Winston 日志记录器：

    ```javascript
    import { getLogger } from "@langchain/langgraph-sdk/logging";

    const logger = getLogger();
    logger.info("Your log message");
    ```

当您从追踪视图导航时，**Filters** 框将自动预填充您刚刚查看的追踪的 Trace ID，因此您可以快速过滤日志，仅查看与您特定追踪执行相关的日志。

![部署服务器日志过滤器](/langsmith/images/lgp-server-logs-filters.png)

## 删除追踪

如果您需要在追踪到期前从 LangSmith 中移除追踪，您可以删除整个项目或删除特定追踪。

### 删除整个项目

- 在 [LangSmith UI](https://smith.langchain.com) 中，选择项目溢出菜单上的 **Delete** 选项。
- 使用 [`delete_tracer_sessions`](https://api.smith.langchain.com/redoc#tag/tracer-sessions/operation/delete_tracer_session_api_v1_sessions__session_id__delete) API 端点。
- 使用 LangSmith SDK 中的 `delete_project()` ([Python](https://reference.langchain.com/python/langsmith/observability/sdk/)) 或 `deleteProject()` ([JS/TS](https://reference.langchain.com/javascript/modules/langsmith.html))。

### 删除特定追踪：

使用 [`delete_runs`](https://api.smith.langchain.com/redoc#tag/run/operation/delete_runs_api_v1_runs_delete_post) API 端点通过追踪 ID 或元数据键值对删除运行。请求体接受：

- `session_id`：将删除范围限定到特定项目。
- `trace_ids`：要删除的追踪 ID 列表。
- `metadata`：删除与给定元数据键值对匹配的所有运行。

有关完整的 API 用法，包括代码示例、每个请求 1000 条追踪的限制、删除时间线和元数据匹配行为，请参阅[用于合规性的数据清除](/langsmith/data-purging-compliance#trace-deletes)。
